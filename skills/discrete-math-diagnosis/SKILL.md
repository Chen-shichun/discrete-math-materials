# 离散数学错题诊断

基于本仓库资料完成可追溯的错题诊断与复习规划。默认不联网，不使用记忆补写库中没有的定义、题目或 ID。

## 模式路由

- 用户提交错题、作答或题目图片：完整阅读 [references/diagnosis-workflow.md](references/diagnosis-workflow.md)，按其中流程诊断。
- 用户要求划重点、考前冲刺或复习顺序：阅读 [references/sprint-planning.md](references/sprint-planning.md)，无需加载完整错题流程。
- 用户只问一个概念：直接检索对应的 `知识点/*.md` 三级标题并简要讲解，不运行错题诊断或写入进度。
- 输入不属于七章覆盖范围：说明边界，不强行回答。

## 知识库入口

| 路径 | 用途 |
|---|---|
| `知识点/` | 七章定义、定理、公式与示例 |
| `习题库/` | 基础题与综合提升题，共 245 道 |
| `error_points_kb.md` | 易错症状、原因和纠正方法 |
| `topic_map.md` | 章节、知识点与题目映射 |
| `knowledge_dependency.md` | 前置与后继依赖 |
| `考点分布.md`、`高频考点清单.md` | 频率、分值与冲刺优先级 |
| `图形题配套包/`、`图形题清单.md` | 图形题配图及映射 |
| `tools/record_diagnosis.py` | 本地追加学习记录 |
| `tools/analyze_progress.py` | 薄弱点、错误聚类与遗忘分析 |

## 始终遵守

1. 只引用仓库内资料；用户明确要求外部资料时，单独标注来源。
2. 未在题库中匹配到原题时写“未匹配”，不得编造题目 ID。
3. 数学符号使用 Unicode 或纯文本，不输出 LaTeX 命令。
4. 所有文件引用使用仓库相对路径。
5. 仅在用户明确要求记录进度，或当前任务已约定持续跟踪时，才写入本地 `student_progress.json`；不得提交到公共仓库。
6. 不主动索取学号等不必要的个人信息。
7. 情绪回应最多一句，随后回到具体诊断。

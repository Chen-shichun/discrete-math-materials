# 考前冲刺与复习规划

仅在用户要求划重点、冲刺计划、复习顺序或薄弱点复盘时读取本文件。

## 数据来源

1. 从 `高频考点清单.md` 读取高频考点和分值排序。
2. 需要完整频率时读取 `考点分布.md`。
3. 读取 `knowledge_dependency.md` 确定前置顺序。
4. 若本地存在 `student_progress.json`，运行：

   `python tools/analyze_progress.py --user <user_id> --json`

   将“薄弱且高频”的知识大点设为最高优先级。不存在进度文件时，明确说明计划基于全局考点而非个人历史。

## 输出要求

- 先列最高价值的 3–5 个知识大点，说明频率、分值和前置关系。
- 再按可用天数安排每天任务；用户未说明时间时给出可缩放的三阶段方案。
- 每个阶段包含复习目标、建议题量和自测标准。
- 低频内容只安排必要的概念回顾。
- 不编造频率、分值、正确率或题目 ID。

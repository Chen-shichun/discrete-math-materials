## 代数系统概念层级

```
广群（封闭性）
  └─ 半群（封闭性 + 结合律）
       └─ 独异点/含幺半群（半群 + 单位元）
            └─ 群（独异点 + 每个元素有逆元）
                 └─ 阿贝尔群/交换群（群 + 交换律）
```

---

## 凯莱表读法速查

| 观察特征 | 对应性质 |
|---------|---------|
| 表中所有元素都在集合内 | 封闭性 |
| 某行/列与表头完全相同 | 该行/列元素为单位元 |
| 某行/列全为同一个元素 | 该行/列元素为零元 |
| 每行每列都是集合元素的排列 | 群的性质（消去律） |
| 表关于主对角线对称 | 运算满足交换律 |
| 单位元在每行每列恰好出现一次 | 每个元素有逆元 |

## 使用说明

1. 题1和题5为凯莱表专题，分别展示加法群和乘法群的运算表，可用于对比不同群的结构。
2. 题2~题4为代数系统基本概念示意图，通过高亮行/列直观展示单位元和零元的特征。
3. 题6为子群判定图，同心圆直观展示包含关系，右侧列出判定条件便于记忆。
4. 题目难度与原习题库对齐：题1~题4为基础概念题，题5~题6为中等应用题（群的性质与子群判定）。
5. 所有图片均为黑白主色调（单位元用蓝色高亮、零元用红色高亮辅助识别），打印友好。
6. 运算符号统一使用「·」表示二元运算，零元用「θ」表示，逆元用「a逆」表示，确保字符渲染正常。

# 第3章 集合论

## 一、集合的基本概念〔CH3-01〕

### 集合与元素〔CH3-01-01〕

**集合**：一些可确定的、可分辨的事物构成的整体。通常用大写字母 A, B, C 表示集合。

**元素**：组成集合的每个事物称为该集合的元素，通常用小写字母 a, b, c 表示。

**属于**：若 a 是集合 A 的元素，记作 **a ∈ A**；若 a 不是 A 的元素，记作 **a ∉ A**。

集合的性质：
- **确定性**：一个元素是否属于某集合是确定的。
- **互异性**：集合中的元素互不相同。
- **无序性**：集合中元素的排列顺序无关。

示例1：A = {1, 2, 3}，则 2 ∈ A，4 ∉ A。
示例2：{1, 2, 3} 与 {3, 2, 1} 是同一个集合（无序性）。
示例3：{1, 1, 2} 与 {1, 2} 是同一个集合（互异性，重复元素只算一次）。

### 集合的表示方法〔CH3-01-02〕

**列举法**：将集合的元素逐一列出，元素之间用逗号分隔，用花括号括起。适用于元素有限或有明显规律的集合。

**描述法（谓词表示法）**：用谓词描述元素的共同性质，形式为 A = {x | P(x)}，表示所有满足性质 P(x) 的 x 构成的集合。

**文氏图（Venn图）**：用平面上的封闭曲线内部表示集合，用于直观展示集合间的关系和运算。

示例1：列举法：A = {a, b, c, d}，B = {1, 3, 5, 7, ...}（正奇数集）。
示例2：描述法：A = {x | x 是偶数且 x > 0}，表示所有正偶数构成的集合。
示例3：描述法：B = {x | x ∈ Z 且 x^2 < 10} = {-3, -2, -1, 0, 1, 2, 3}。

### 集合间的关系〔CH3-01-03〕

**子集（包含）**：若集合 A 的每个元素都是 B 的元素，则称 A 是 B 的子集，记作 **A ⊆ B**（读作 A 包含于 B），即 ∀x(x ∈ A → x ∈ B)。

**真子集**：若 A ⊆ B 且 A ≠ B，则称 A 是 B 的真子集，记作 **A ⊂ B**。

**集合相等**：若 A ⊆ B 且 B ⊆ A，则称 A 与 B 相等，记作 **A = B**。即两个集合有完全相同的元素。

**不包含**：若 A 不是 B 的子集，记作 A ⊈ B，即 ∃x(x ∈ A 且 x ∉ B)。

示例1：{1, 2} ⊆ {1, 2, 3}，且 {1, 2} ⊂ {1, 2, 3}（真子集）。
示例2：{x | x^2 = 1} = {-1, 1}，两个集合元素完全相同故相等。
示例3：{1, 2} ⊈ {2, 3, 4}，因为 1 ∈ {1,2} 但 1 ∉ {2,3,4}。

### 特殊集合〔CH3-01-04〕

**空集**：不含任何元素的集合，记作 **∅**。空集是任何集合的子集，即 ∅ ⊆ A 对任意集合 A 成立。空集是唯一的。

**全集**：在一定范围内，所有集合都是某一固定集合的子集，这个固定集合称为全集，记作 **E**（或 U）。全集具有相对性，依赖于讨论的问题范围。

**幂集**：集合 A 的所有子集构成的集合称为 A 的幂集，记作 **P(A)**（或 2^A）。即 P(A) = {x | x ⊆ A}。

**幂集基数公式**：若 A 是有 n 个元素的有穷集，则 **|P(A)| = 2^n**。

示例1：∅ ⊆ {1, 2, 3}，空集是任意集合的子集。
示例2：A = {1, 2}，则 P(A) = {∅, {1}, {2}, {1, 2}}，|P(A)| = 4 = 2^2。
示例3：P(∅) = {∅}，注意空集的幂集不是空集，而是含一个元素（空集本身）的集合。

## 二、集合的运算〔CH3-02〕

### 基本运算〔CH3-02-01〕

**并运算**：A ∪ B = {x | x ∈ A 或 x ∈ B}，由属于 A 或属于 B 的所有元素组成。

**交运算**：A ∩ B = {x | x ∈ A 且 x ∈ B}，由同时属于 A 和 B 的元素组成。

**差运算（相对补）**：A - B = {x | x ∈ A 且 x ∉ B}，由属于 A 但不属于 B 的元素组成。

**补运算（绝对补）**：~A = E - A = {x | x ∉ A}，由全集中不属于 A 的所有元素组成。（也记作 A^c 或 Ā）

**对称差**：A ⊕ B = (A - B) ∪ (B - A) = (A ∪ B) - (A ∩ B)，由属于 A 或 B 但不同时属于两者的元素组成。

示例1：A = {1, 2, 3}，B = {2, 3, 4}，则 A ∪ B = {1, 2, 3, 4}，A ∩ B = {2, 3}。
示例2：A = {1, 2, 3}，B = {2, 3, 4}，则 A - B = {1}，B - A = {4}，A ⊕ B = {1, 4}。
示例3：设全集 E = {1, 2, 3, 4, 5}，A = {1, 2}，则 ~A = {3, 4, 5}。

### 集合运算律〔CH3-02-02〕

以下运算律对任意集合 A, B, C 成立：

**幂等律**：**A ∪ A = A**，**A ∩ A = A**
**结合律**：**(A ∪ B) ∪ C = A ∪ (B ∪ C)**，**(A ∩ B) ∩ C = A ∩ (B ∩ C)**
**交换律**：**A ∪ B = B ∪ A**，**A ∩ B = B ∩ A**
**分配律**：**A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)**，**A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)**
**同一律**：**A ∪ ∅ = A**，**A ∩ E = A**
**零律**：**A ∪ E = E**，**A ∩ ∅ = ∅**
**排中律（互补律）**：**A ∪ ~A = E**
**矛盾律**：**A ∩ ~A = ∅**
**双重否定律**：**~~A = A**
**吸收律**：**A ∪ (A ∩ B) = A**，**A ∩ (A ∪ B) = A**
**德摩根律**：**~(A ∪ B) = ~A ∩ ~B**，**~(A ∩ B) = ~A ∪ ~B**
**德摩根律（相对形式）**：**A - (B ∪ C) = (A - B) ∩ (A - C)**，**A - (B ∩ C) = (A - B) ∪ (A - C)**

示例1：用吸收律化简 A ∪ (A ∩ B) = A。
示例2：用德摩根律：~({1,2} ∪ {2,3}) = ~{1,2,3} = ~{1,2} ∩ ~{2,3}。
示例3：用分配律：A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)，与命题逻辑分配律形式一致。

### 集合包含的证明方法〔CH3-02-03〕

证明 A ⊆ B 的常用方法：任取 x ∈ A，证明 x ∈ B（即 ∀x(x ∈ A → x ∈ B)）。

证明 A = B 的常用方法：分别证明 A ⊆ B 和 B ⊆ A。

证明集合等式也可利用已知的运算律（如德摩根律、分配律等）通过等值演算推导。

示例1：证明 A ∩ B ⊆ A。任取 x ∈ A ∩ B，则 x ∈ A 且 x ∈ B，故 x ∈ A，因此 A ∩ B ⊆ A。
示例2：证明 A - B = A ∩ ~B。任取 x ∈ A - B，则 x ∈ A 且 x ∉ B，即 x ∈ A 且 x ∈ ~B，故 x ∈ A ∩ ~B；反之同理，故等式成立。
示例3：用运算律证明 A ∪ (B - A) = A ∪ B。A ∪ (B - A) = A ∪ (B ∩ ~A) = (A ∪ B) ∩ (A ∪ ~A) = (A ∪ B) ∩ E = A ∪ B。

## 三、有穷集合的计数〔CH3-03〕

### 容斥原理（包含排斥原理）〔CH3-03-01〕

**两个集合的容斥原理**：** |A ∪ B| = |A| + |B| - |A ∩ B|**

**三个集合的容斥原理**：
**|A ∪ B ∪ C| = |A| + |B| + |C| - |A ∩ B| - |A ∩ C| - |B ∩ C| + |A ∩ B ∩ C|**

**n 个集合的容斥原理**：
|A1 ∪ A2 ∪ ... ∪ An| = Σ|Ai| - Σ|Ai ∩ Aj| + Σ|Ai ∩ Aj ∩ Ak| - ... + (-1)^(n-1)|A1 ∩ ... ∩ An|

规律：奇数个集合的交集前为正号，偶数个集合的交集前为负号。

示例1：某班有30人，选数学的20人，选物理的15人，都选的10人。问至少选一门的人数：|数∪物| = 20 + 15 - 10 = 25人。
示例2：100人中，会英语的60人，会日语的40人，会法语的30人，英日都会的20人，英法都会的15人，日法都会的10人，三门都会的5人。至少会一门的人数 = 60+40+30-20-15-10+5 = 90人。
示例3：求1到100中能被2或3整除的数的个数。能被2整除的50个，能被3整除的33个，能被6整除的16个，故 |A∪B| = 50+33-16 = 67个。

### 补集计数〔CH3-03-02〕

利用全集与补集的关系计数：**|~A| = |E| - |A|**

结合容斥原理可求"都不满足"的元素个数：
|~A ∩ ~B| = |E| - |A ∪ B| = |E| - |A| - |B| + |A ∩ B|

示例1：全班50人，数学及格40人，英语及格35人，都及格30人。都不及格的人数 = 50 - (40+35-30) = 5人。
示例2：1到100中既不能被2也不能被3整除的数 = 100 - 67 = 33个（接前例）。
示例3：某年级200人，参加数学竞赛80人，物理竞赛60人，都参加的20人。两科都不参加的 = 200 - (80+60-20) = 80人。

## 四、二元关系〔CH3-04〕

### 有序对与笛卡尔积〔CH3-04-01〕

**有序对（序偶）**：由两个元素 x 和 y 按一定顺序组成的二元组，记作 **<x, y>**（或 (x, y)）。x 称为第一元素，y 称为第二元素。有序对具有顺序性：<x, y> = <u, v> 当且仅当 x = u 且 y = v。

**笛卡尔积（直积）**：设 A, B 为集合，A 与 B 的笛卡尔积记作 **A × B**，定义为 A × B = {<x, y> | x ∈ A 且 y ∈ B}。

笛卡尔积的性质：
- |A × B| = |A| × |B|（A、B为有穷集时）
- A × ∅ = ∅，∅ × A = ∅
- 笛卡尔积一般不满足交换律和结合律
- 笛卡尔积对并和交满足分配律：A × (B ∪ C) = (A × B) ∪ (A × C)

示例1：A = {1, 2}，B = {a, b}，则 A × B = {<1,a>, <1,b>, <2,a>, <2,b>}，|A × B| = 4。
示例2：<1, 2> ≠ <2, 1>，因为第一元素不同（有序对的顺序性）。
示例3：A = {1}，则 A × A = {<1, 1>}，注意 {<1,1>} 与 {1} 不同。

### 二元关系的定义与表示〔CH3-04-02〕

**二元关系**：设 A, B 为集合，A × B 的任何子集 R 称为从 A 到 B 的二元关系，记作 **R ⊆ A × B**。若 <x, y> ∈ R，记作 xRy；若 <x, y> ∉ R，记作 xRy 不成立。当 A = B 时，称 R 为 A 上的二元关系。

**特殊关系**：
- **空关系**：∅（不含任何有序对）
- **全域关系**：E_A = A × A（A 上所有有序对都有关系）
- **恒等关系**：I_A = {<x, x> | x ∈ A}

**关系的表示方法**：集合表示法、关系矩阵、关系图。

**关系矩阵**：设 A = {x1, ..., xm}，B = {y1, ..., yn}，R ⊆ A × B，关系矩阵 M_R = (rij)（m×n 矩阵），其中 rij = 1 若 <xi, yj> ∈ R，否则 rij = 0。

示例1：A = {1, 2}，A 上的关系 R = {<1,1>, <1,2>, <2,1>}，则 <1,2> ∈ R 即 1R2，<2,2> ∉ R。
示例2：A = {1, 2, 3}，恒等关系 I_A = {<1,1>, <2,2>, <3,3>}，全域关系 E_A 含 9 个有序对。
示例3：A = {1, 2}，R = {<1,2>, <2,1>} 的关系矩阵为 [[0,1],[1,0]]（行对应第一元素，列对应第二元素）。

### 关系的运算〔CH3-04-03〕

**定义域**：dom R = {x | ∃y(<x, y> ∈ R)}，R 中所有有序对的第一元素构成的集合。

**值域**：ran R = {y | ∃x(<x, y> ∈ R)}，R 中所有有序对的第二元素构成的集合。

**域**：fld R = dom R ∪ ran R。

**逆关系**：R^(-1) = {<y, x> | <x, y> ∈ R}，将 R 中每个有序对的元素顺序颠倒。

**复合关系**：设 R ⊆ A × B，S ⊆ B × C，则 R 与 S 的复合（右复合）记作 **R ∘ S** = {<x, z> | ∃y(<x, y> ∈ R 且 <y, z> ∈ S)}。

**关系的幂**：设 R 为 A 上的关系，n 为自然数，则 R^0 = I_A（恒等关系），R^(n+1) = R^n ∘ R。

复合运算的性质：
- (R ∘ S) ∘ T = R ∘ (S ∘ T)（结合律）
- (R ∘ S)^(-1) = S^(-1) ∘ R^(-1)
- R ∘ I_A = I_A ∘ R = R

示例1：R = {<1,2>, <2,3>, <3,1>}，则 dom R = {1,2,3}，ran R = {1,2,3}，R^(-1) = {<2,1>, <3,2>, <1,3>}。
示例2：R = {<1,2>, <2,3>}，S = {<2,4>, <3,5>}，则 R ∘ S = {<1,4>, <2,5>}（通过中间元素 2 和 3 连接）。
示例3：R = {<1,2>, <2,1>}，则 R^2 = R ∘ R = {<1,1>, <2,2>} = I_A，R^3 = R^2 ∘ R = R。

### 关系的性质〔CH3-04-04〕

设 R 是集合 A 上的二元关系：

**自反性**：若 ∀x(x ∈ A → <x, x> ∈ R)，则称 R 在 A 上是自反的。关系矩阵主对角线全为 1，关系图每个顶点都有环。

**反自反性**：若 ∀x(x ∈ A → <x, x> ∉ R)，则称 R 在 A 上是反自反的。关系矩阵主对角线全为 0，关系图每个顶点都无环。

**对称性**：若 ∀x∀y(<x, y> ∈ R → <y, x> ∈ R)，则称 R 是对称的。关系矩阵为对称矩阵，关系图中任何有向边都是双向的。

**反对称性**：若 ∀x∀y(<x, y> ∈ R 且 <y, x> ∈ R → x = y)，则称 R 是反对称的。关系矩阵中关于主对角线对称的元素不能同时为 1（除对角线外），关系图中任何两个不同顶点之间没有双向边。

**传递性**：若 ∀x∀y∀z(<x, y> ∈ R 且 <y, z> ∈ R → <x, z> ∈ R)，则称 R 是传递的。关系图中若有从 x 到 y 的边和 y 到 z 的边，则必有 x 到 z 的边。

注意：自反与反自反不是非此即彼（存在既不自反也不反自反的关系）；对称与反对称也不是非此即彼。

示例1：A = {1,2,3}，R = {<1,1>, <2,2>, <3,3>, <1,2>} 是自反的（对角线全有），但不是对称的（<1,2>无<2,1>）。
示例2：实数集上的"小于"关系 < 是反自反的（x<x不成立）、反对称的、传递的。
示例3：A = {1,2,3}，R = {<1,2>, <2,1>, <1,1>} 既不是自反的（缺<2,2>,<3,3>）也不是反自反的（有<1,1>）；是对称的（<1,2>和<2,1>成对出现）。

### 关系的闭包〔CH3-04-05〕

设 R 是 A 上的关系，R 的**自反闭包 r(R)**、**对称闭包 s(R)**、**传递闭包 t(R)** 是满足以下条件的最小关系：
- r(R) 是自反的，且 R ⊆ r(R)
- s(R) 是对称的，且 R ⊆ s(R)
- t(R) 是传递的，且 R ⊆ t(R)

**闭包的计算公式**：
- **r(R) = R ∪ I_A**（并上恒等关系）
- **s(R) = R ∪ R^(-1)**（并上逆关系）
- **t(R) = R ∪ R^2 ∪ R^3 ∪ ...**（所有正整数次幂的并）

对于有穷集 A（|A| = n），**t(R) = R ∪ R^2 ∪ ... ∪ R^n**（只需算到 n 次幂）。

传递闭包也可用**Warshall算法**高效计算。

示例1：A = {1,2}，R = {<1,2>}，则 r(R) = {<1,2>, <1,1>, <2,2>}，s(R) = {<1,2>, <2,1>}。
示例2：A = {1,2,3}，R = {<1,2>, <2,3>}，则 R^2 = {<1,3>}，R^3 = ∅，t(R) = {<1,2>, <2,3>, <1,3>}。
示例3：A = {1,2,3}，R = {<1,2>, <2,1>, <2,3>}，R^2 = {<1,1>, <1,3>, <2,2>}，R^3 = {<1,2>, <2,1>, <2,3>} = R，t(R) = R ∪ R^2 = {<1,1>,<1,2>,<1,3>,<2,1>,<2,2>,<2,3>}。

## 五、等价关系与偏序关系〔CH3-05〕

### 等价关系与等价类〔CH3-05-01〕

**等价关系**：集合 A 上的关系 R 若同时满足**自反性、对称性、传递性**，则称 R 为 A 上的等价关系。若 <x, y> ∈ R，称 x 等价于 y，记作 x ~ y。

**等价类**：设 R 是 A 上的等价关系，x ∈ A，A 中与 x 等价的所有元素构成的集合称为 x 关于 R 的等价类，记作 **[x]_R** = {y | y ∈ A 且 <x, y> ∈ R}。

等价类的性质：
- ∀x ∈ A，[x]_R 非空且 x ∈ [x]_R
- 若 <x, y> ∈ R，则 [x]_R = [y]_R
- 若 <x, y> ∉ R，则 [x]_R ∩ [y]_R = ∅
- 所有等价类的并集等于 A

**商集**：A 上等价关系 R 的所有等价类构成的集合称为 A 关于 R 的商集，记作 **A/R** = {[x]_R | x ∈ A}。

示例1：整数集 Z 上的模 3 同余关系 R = {<x,y> | x ≡ y (mod 3)} 是等价关系。等价类为 [0] = {...,-3,0,3,...}，[1] = {...,-2,1,4,...}，[2] = {...,-1,2,5,...}。
示例2：A = {1,2,3,4}，R = {<1,1>,<2,2>,<3,3>,<4,4>,<1,2>,<2,1>,<3,4>,<4,3>} 是等价关系。等价类 [1] = [2] = {1,2}，[3] = [4] = {3,4}，商集 A/R = {{1,2}, {3,4}}。
示例3：人的"同龄"关系是等价关系（自反、对称、传递），每个年龄组是一个等价类。

### 集合的划分〔CH3-05-02〕

**划分**：设 A 为非空集合，若 A 的子集族 π（π ⊆ P(A)）满足：
1. ∅ ∉ π（每个分块非空）
2. ∀x∀y(x, y ∈ π 且 x ≠ y → x ∩ y = ∅)（分块之间不交）
3. ∪π = A（所有分块的并为 A）

则称 π 为 A 的一个划分，π 中的元素称为划分块。

**等价关系与划分的对应**：集合 A 上的等价关系 R 与 A 的划分一一对应。由等价关系 R 得到的商集 A/R 就是 A 的一个划分；反之，由 A 的任一划分 π 可定义等价关系 R = {<x,y> | x, y 属于 π 的同一划分块}。

示例1：A = {1,2,3}，{{1,2}, {3}} 是 A 的一个划分（两个非空不交子集，并且为 A）。
示例2：A = {1,2,3}，{{1,2}, {2,3}} 不是划分（{1,2}∩{2,3} = {2} ≠ ∅）。
示例3：A = {1,2,3,4}，划分 π = {{1}, {2,3}, {4}} 对应的等价关系 R = I_A ∪ {<2,3>, <3,2>}。

### 偏序关系与哈斯图〔CH3-05-03〕

**偏序关系**：集合 A 上的关系 R 若同时满足**自反性、反对称性、传递性**，则称 R 为 A 上的偏序关系，记作 **≼**。集合 A 与偏序关系 ≼ 一起称为偏序集，记作 <A, ≼>。

**可比**：在偏序集 <A, ≼> 中，若 x ≼ y 或 y ≼ x，则称 x 与 y 可比；否则称不可比。

**全序（线序）**：若偏序集中任意两个元素都可比，则称该偏序关系为全序关系。

**盖住**：设 <A, ≼> 为偏序集，x, y ∈ A，若 x ≺ y（即 x ≼ y 且 x ≠ y）且不存在 z ∈ A 使得 x ≺ z ≺ y，则称 y 盖住 x。

**哈斯图**：偏序集的一种简化关系图。画法：
1. 每个元素用一个点表示，小元素在下方，大元素在上方。
2. 若 y 盖住 x，则在 x 与 y 之间连一条线（省略自反环和传递产生的边）。

示例1：集合 A = {1, 2, 3, 6} 上的整除关系是偏序关系。1 最小在最下方，2 和 3 盖住 1，6 盖住 2 和 3，哈斯图为菱形。
示例2：幂集 P({a,b}) = {∅, {a}, {b}, {a,b}} 上的包含关系 ⊆ 是偏序关系。∅ 在最下方，{a},{b} 盖住 ∅，{a,b} 盖住 {a},{b}。
示例3：实数集上的 ≤ 关系是全序关系（任意两实数都可比）。

### 偏序集中的特殊元素〔CH3-05-04〕

设 <A, ≼> 为偏序集，B ⊆ A：

**最大元**：若 ∃b ∈ B，使得 ∀x(x ∈ B → x ≼ b)，则称 b 为 B 的最大元。
**最小元**：若 ∃b ∈ B，使得 ∀x(x ∈ B → b ≼ x)，则称 b 为 B 的最小元。
**极大元**：若 ∃b ∈ B，使得不存在 x ∈ B 满足 b ≺ x，则称 b 为 B 的极大元。
**极小元**：若 ∃b ∈ B，使得不存在 x ∈ B 满足 x ≺ b，则称 b 为 B 的极小元。

**上界**：若 ∃a ∈ A，使得 ∀x(x ∈ B → x ≼ a)，则称 a 为 B 的上界。
**下界**：若 ∃a ∈ A，使得 ∀x(x ∈ B → a ≼ x)，则称 a 为 B 的下界。
**最小上界（上确界）**：B 的上界中的最小元，记作 sup B 或 lub(B)。
**最大下界（下确界）**：B 的下界中的最大元，记作 inf B 或 glb(B)。

注意：最大元/最小元必须属于 B 且与 B 中所有元素可比；极大元/极小元属于 B 但不一定与所有元素可比（没有比它更大/更小的即可）。上界/下界属于 A（不一定属于 B）。

示例1：A = {2, 3, 6, 12, 18}，整除关系。B = {2, 3, 6}。最大元 = 6，最小元不存在（2和3不可比），极大元 = 6，极小元 = 2, 3。
示例2：上例中 B = {6, 12, 18}。最大元不存在（12和18不可比），最小元 = 6，极大元 = 12, 18，极小元 = 6。上界不存在（没有同时是12和18倍数的元素在A中），下界 = 2, 3, 6，下确界 = 6。
示例3：偏序集 <P({a,b}), ⊆>，B = {{a}, {b}}。最大元不存在，最小元不存在，极大元 = {a}, {b}，极小元 = {a}, {b}。上界 = {a,b}，下界 = ∅，上确界 = {a,b}，下确界 = ∅。

## 六、函数〔CH3-06〕

### 函数的定义〔CH3-06-01〕

**函数（映射）**：设 F 为二元关系，若 ∀x ∈ dom F 都存在唯一的 y ∈ ran F 使得 <x, y> ∈ F，则称 F 为函数（或映射）。函数通常用 f, g, h 表示。若 <x, y> ∈ f，记作 y = f(x)，称 y 为 x 在 f 下的函数值（像）。

**从 A 到 B 的函数**：设 A, B 为集合，若函数 f 满足 dom f = A 且 ran f ⊆ B，则称 f 为从 A 到 B 的函数，记作 **f: A → B**。

**函数集合**：所有从 A 到 B 的函数构成的集合记作 **B^A** = {f | f: A → B}。若 |A| = m，|B| = n，则 |B^A| = n^m。

**像与完全原像**：设 f: A → B，A1 ⊆ A，B1 ⊆ B。
- A1 在 f 下的像：f(A1) = {f(x) | x ∈ A1}
- B1 在 f 下的完全原像：f^(-1)(B1) = {x | x ∈ A 且 f(x) ∈ B1}

示例1：f = {<1,a>, <2,b>, <3,a>} 是函数（每个第一元素唯一对应一个第二元素），dom f = {1,2,3}，ran f = {a,b}。
示例2：A = {1,2}，B = {a,b}，则 B^A 含 2^2 = 4 个函数：f1={<1,a>,<2,a>}, f2={<1,a>,<2,b>}, f3={<1,b>,<2,a>}, f4={<1,b>,<2,b>}。
示例3：f: Z → Z，f(x) = x^2，则 f({-1, 0, 1}) = {0, 1}，f^(-1)({4}) = {-2, 2}。

### 函数的性质〔CH3-06-02〕

设 f: A → B：

**单射（入射）**：若 ∀x1∀x2(x1 ≠ x2 → f(x1) ≠ f(x2))，即不同的自变量对应不同的函数值，则称 f 为单射。等价于 f(x1) = f(x2) → x1 = x2。

**满射**：若 ran f = B，即 ∀y(y ∈ B → ∃x(x ∈ A 且 f(x) = y))，则称 f 为满射（B 中每个元素都有原像）。

**双射（一一对应）**：若 f 既是单射又是满射，则称 f 为双射。双射建立了 A 与 B 元素之间的一一对应，此时 |A| = |B|（有限集时）。

示例1：f: R → R，f(x) = 2x 是双射（单射：x1≠x2→2x1≠2x2；满射：对任意y，x=y/2∈R使f(x)=y）。
示例2：f: R → R，f(x) = x^2 不是单射（f(1)=f(-1)=1），也不是满射（负数没有原像）。
示例3：f: N → N，f(n) = n+1 是单射但不是满射（0 没有原像）。

### 复合函数与逆函数〔CH3-06-03〕

**复合函数**：设 f: A → B，g: B → C，则 f 与 g 的复合函数 g ∘ f: A → C 定义为 (g ∘ f)(x) = g(f(x))。注意复合顺序：先作用 f 再作用 g。

复合函数的性质：
- 若 f 和 g 都是单射，则 g ∘ f 是单射
- 若 f 和 g 都是满射，则 g ∘ f 是满射
- 若 f 和 g 都是双射，则 g ∘ f 是双射

**逆函数**：设 f: A → B 是双射，则 f 的逆关系 f^(-1) 也是函数，称为 f 的逆函数，f^(-1): B → A，且 f^(-1)(y) = x 当且仅当 f(x) = y。只有双射才有逆函数。

逆函数的性质：
- f^(-1) ∘ f = I_A（A 上的恒等函数）
- f ∘ f^(-1) = I_B（B 上的恒等函数）
- (f^(-1))^(-1) = f

示例1：f: R → R, f(x)=2x，g: R → R, g(x)=x+1，则 (g∘f)(x) = g(2x) = 2x+1，(f∘g)(x) = f(x+1) = 2x+2，注意 g∘f ≠ f∘g。
示例2：f: R → R, f(x)=2x 是双射，逆函数 f^(-1)(x) = x/2。验证：f^(-1)(f(x)) = f^(-1)(2x) = x。
示例3：f: {1,2,3} → {a,b,c}, f={<1,a>,<2,b>,<3,c>} 是双射，f^(-1)={<a,1>,<b,2>,<c,3>}。

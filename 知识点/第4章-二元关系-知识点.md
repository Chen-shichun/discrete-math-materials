# 第4章 二元关系

## 一、有序对与笛卡尔积〔CH4-01〕

### 有序对〔CH4-01-01〕

**定义**：由两个元素x和y按一定顺序组成的二元组称为有序对（序偶），记作<x,y>。其中x称为第一元素，y称为第二元素。

**有序对的相等条件**：<x,y> = <u,v> 当且仅当 x=u 且 y=v。

**核心性质**：有序对具有顺序性，一般情况下 <x,y> ≠ <y,x>（除非x=y）。

**示例1**：<1,2> ≠ <2,1>，因为第一元素1≠2。

**示例2**：已知<x+1, 3> = <4, y-2>，由相等条件得x+1=4且3=y-2，解得x=3，y=5。

**示例3**：坐标平面上的点(3,5)就是一个有序对，横坐标3和纵坐标5不可交换。

### 笛卡尔积〔CH4-01-02〕

**定义**：设A、B为集合，以A中元素为第一元素、B中元素为第二元素构成的所有有序对组成的集合，称为A与B的笛卡尔积（直积），记作 A×B = { <x,y> | x∈A 且 y∈B }。

**基数公式**：**若|A|=m，|B|=n，则|A×B|=m×n**。

**n阶笛卡尔积**：A1×A2×...×An = { <x1,x2,...,xn> | xi∈Ai }。

**示例1**：A={1,2}，B={a,b}，则A×B={<1,a>,<1,b>,<2,a>,<2,b>}，共4个元素。

**示例2**：A={1}，B={2,3,4}，则A×B={<1,2>,<1,3>,<1,4>}，|A×B|=1×3=3。

**示例3**：R×R = {<x,y>|x,y∈R} 表示整个坐标平面，即二维实数空间。

### 笛卡尔积的性质〔CH4-01-03〕

**基本性质**：
- 笛卡尔积一般不满足交换律：**A×B ≠ B×A**（除非A=B或A=∅或B=∅）
- 笛卡尔积一般不满足结合律：(A×B)×C ≠ A×(B×C)（有序对层次不同）
- 空集性质：A×∅ = ∅×A = ∅
- **对并运算的分配律**：A×(B∪C) = (A×B)∪(A×C)
- **对交运算的分配律**：A×(B∩C) = (A×B)∩(A×C)
- 包含单调性：若A⊆B且C⊆D，则A×C ⊆ B×D

**示例1**：A={1}，B={2}，A×B={<1,2>}，B×A={<2,1>}，两者不相等，验证交换律不成立。

**示例2**：验证分配律：A={1}，B={2}，C={3}，A×(B∪C)={<1,2>,<1,3>}，(A×B)∪(A×C)={<1,2>}∪{<1,3>}={<1,2>,<1,3>}，两者相等。

**示例3**：A⊆B时，A×C⊆B×C。如A={1}⊆B={1,2}，C={3}，A×C={<1,3>}⊆B×C={<1,3>,<2,3>}。

## 二、二元关系的基本概念〔CH4-02〕

### 二元关系的定义〔CH4-02-01〕

**定义**：设A、B为集合，**A×B的任何子集R都称为从A到B的二元关系**，记作 R⊆A×B。当A=B时，称R为A上的二元关系。

**关系的记法**：若<x,y>∈R，记作 xRy；若<x,y>∉R，记作 xRy 不成立。

**定义域与值域**：
- 定义域 dom(R) = { x | ∃y(<x,y>∈R) }（R中所有有序对的第一元素）
- 值域 ran(R) = { y | ∃x(<x,y>∈R) }（R中所有有序对的第二元素）
- 域 fld(R) = dom(R) ∪ ran(R)

**示例1**：A={1,2,3}，R={<1,2>,<2,3>,<1,3>}是A上的二元关系，dom(R)={1,2}，ran(R)={2,3}。

**示例2**：从A={1,2}到B={a,b}的关系R={<1,a>,<2,b>}，dom(R)={1,2}=A，ran(R)={a,b}=B。

**示例3**：实数集R上的"小于"关系 < = {<x,y>|x,y∈R且x<y}，dom(<)=R，ran(<)=R。

### 关系的表示方法〔CH4-02-02〕

**三种表示方法**：

1. **集合表示法**：直接列出关系中的所有有序对，如R={<1,1>,<1,2>,<2,2>}。

2. **关系矩阵**：设A={x1,x2,...,xm}，B={y1,y2,...,yn}，R⊆A×B，关系矩阵M_R=(m_ij)（m×n 矩阵），其中 **m_ij = 1 若 <xi,yj>∈R，m_ij = 0 若 <xi,yj>∉R**。

3. **关系图**：以集合元素为顶点，若<x,y>∈R则从x到y画一条有向边。自环表示<x,x>∈R。

**示例1**：A={1,2,3}，R={<1,2>,<2,3>,<3,1>}，关系矩阵为：
```
    1 2 3
1 [ 0 1 0 ]
2 [ 0 0 1 ]
3 [ 1 0 0 ]
```

**示例2**：A={1,2}，R={<1,1>,<1,2>,<2,1>}的关系图：顶点1有自环，1→2有边，2→1有边，顶点2无自环。

**示例3**：恒等关系I_A的关系矩阵是单位矩阵（对角线全1，其余全0）。

### 特殊关系〔CH4-02-03〕

**空关系**：∅（不含任何有序对），空关系是任何集合上的关系。

**全域关系**：**E_A = A×A**（A上所有可能的有序对都在关系中）。

**恒等关系**：**I_A = { <x,x> | x∈A }**（每个元素只与自身有关系）。

**小于等于关系**：L_A = { <x,y> | x,y∈A 且 x≤y }（A为实数集子集）。

**整除关系**：D_A = { <x,y> | x,y∈A 且 x整除y }（A为正整数集子集）。

**包含关系**：⊆ = { <x,y> | x,y∈P(A) 且 x⊆y }。

**示例1**：A={1,2,3}，E_A={<1,1>,<1,2>,<1,3>,<2,1>,<2,2>,<2,3>,<3,1>,<3,2>,<3,3>}，共9个有序对。

**示例2**：A={1,2,3}，I_A={<1,1>,<2,2>,<3,3>}，关系矩阵为单位矩阵。

**示例3**：A={1,2,3,6}，整除关系D_A={<1,1>,<1,2>,<1,3>,<1,6>,<2,2>,<2,6>,<3,3>,<3,6>,<6,6>}。

## 三、关系的运算〔CH4-03〕

### 关系的集合运算〔CH4-03-01〕

**定义**：关系是集合（A×B的子集），因此集合的所有运算都适用于关系。

设R和S是从A到B的关系：
- **并**：R∪S = { <x,y> | <x,y>∈R 或 <x,y>∈S }
- **交**：R∩S = { <x,y> | <x,y>∈R 且 <x,y>∈S }
- **差**：R-S = { <x,y> | <x,y>∈R 且 <x,y>∉S }
- **补**：~R = E_A - R = { <x,y> | <x,y>∉R }（相对于全域关系）

**示例1**：R={<1,2>,<2,3>}，S={<1,2>,<3,1>}，则R∪S={<1,2>,<2,3>,<3,1>}，R∩S={<1,2>}。

**示例2**：A={1,2}，R={<1,1>}，E_A={<1,1>,<1,2>,<2,1>,<2,2>}，则~R=E_A-R={<1,2>,<2,1>,<2,2>}。

**示例3**：R-S与S-R一般不同。R={<1,2>}，S={<2,1>}，R-S={<1,2>}，S-R={<2,1>}。

### 逆关系〔CH4-03-02〕

**定义**：设R⊆A×B，R的逆关系（反关系）**R^(-1) = { <y,x> | <x,y>∈R }**，即将R中每个有序对的两个元素互换位置。

**基本性质**：
- **(R^(-1))^(-1) = R**（逆的逆等于原关系）
- **(R∪S)^(-1) = R^(-1)∪S^(-1)**
- **(R∩S)^(-1) = R^(-1)∩S^(-1)**
- **(R-S)^(-1) = R^(-1)-S^(-1)**
- R⊆S 当且仅当 R^(-1)⊆S^(-1)
- 关系矩阵：M(R^(-1)) = M_R^T（转置矩阵）

**示例1**：R={<1,2>,<2,3>,<3,1>}，则R^(-1)={<2,1>,<3,2>,<1,3>}。

**示例2**：实数集上"小于"关系<的逆关系是"大于"关系>，因为<x,y>∈<当且仅当<y,x>∈>。

**示例3**：恒等关系的逆仍是自身：I_A^(-1)=I_A，因为<x,x>互换后仍为<x,x>。

### 复合关系〔CH4-03-03〕

**定义**：设R⊆A×B，S⊆B×C，R与S的复合（右复合）**R∘S = { <x,z> | ∃y∈B(<x,y>∈R 且 <y,z>∈S) }**。

**运算规则**：先经过R，再经过S。找到R中第二元素与S中第一元素相同的配对，连接第一和第三元素。

**基本性质**：
- **复合运算一般不满足交换律**：R∘S ≠ S∘R
- **复合运算满足结合律**：(R∘S)∘T = R∘(S∘T)
- **逆与复合的关系**：**(R∘S)^(-1) = S^(-1)∘R^(-1)**（逆的复合等于逆的反序复合）
- 复合对并的分配：R∘(S∪T) = (R∘S)∪(R∘T)
- 复合对交的次分配：R∘(S∩T) ⊆ (R∘S)∩(R∘T)（一般只有包含，不等）

**示例1**：R={<1,2>,<2,3>}，S={<2,4>,<3,5>}，R∘S：<1,2>→<2,4>得<1,4>；<2,3>→<3,5>得<2,5>，故R∘S={<1,4>,<2,5>}。

**示例2**：验证(R∘S)^(-1)=S^(-1)∘R^(-1)：上例中R∘S={<1,4>,<2,5>}，其逆为{<4,1>,<5,2>}；S^(-1)={<4,2>,<5,3>}，R^(-1)={<2,1>,<3,2>}，S^(-1)∘R^(-1)={<4,1>,<5,2>}，两者相等。

**示例3**：R={<1,2>}，S={<2,1>}，R∘S={<1,1>}，S∘R={<2,2>}，验证交换律不成立。

### 关系的幂运算〔CH4-03-04〕

**定义**：设R是A上的关系，n为自然数：
- **R^0 = I_A**（零次幂为恒等关系）
- **R^1 = R**
- **R^(n+1) = R^n ∘ R**（n+1次幂为n次幂与R的复合）

**基本性质**：
- **R^m ∘ R^n = R^(m+n)**（指数加法律）
- **(R^m)^n = R^(m×n)**（指数乘法律）
- 有穷集合上的关系幂运算具有周期性：存在s,t使得R^s=R^t（s<t），之后进入循环

**示例1**：A={1,2,3}，R={<1,2>,<2,3>}，R^2=R∘R={<1,3>}（<1,2>→<2,3>），R^3=R^2∘R=∅（<1,3>无后续），R^4=∅。

**示例2**：R={<1,2>,<2,1>}，R^2={<1,1>,<2,2>}=I_A，R^3=R^2∘R=I_A∘R=R，R^4=I_A，呈现周期为2的循环。

**示例3**：恒等关系I_A的任何次幂都是自身：I_A^n=I_A，因为I_A∘I_A=I_A。

## 四、关系的性质〔CH4-04〕

### 自反性与反自反性〔CH4-04-01〕

**自反性定义**：设R是A上的关系，若**∀x∈A，<x,x>∈R**，则称R在A上是自反的。

**反自反性定义**：设R是A上的关系，若**∀x∈A，<x,x>∉R**，则称R在A上是反自反的。

**判定特征**：
- 自反：关系矩阵对角线全为1；关系图每个顶点都有自环
- 反自反：关系矩阵对角线全为0；关系图每个顶点都没有自环
- **注意：存在既不是自反也不是反自反的关系**（部分顶点有自环、部分没有）

**示例1**：A={1,2,3}，R={<1,1>,<2,2>,<3,3>,<1,2>}，所有对角线元素都在R中，R是自反的。

**示例2**：A={1,2,3}，R={<1,2>,<2,3>}，没有任何对角线元素，R是反自反的。

**示例3**：A={1,2,3}，R={<1,1>,<2,3>}，<1,1>在但<2,2>和<3,3>不在，R既不是自反的也不是反自反的。

### 对称性与反对称性〔CH4-04-02〕

**对称性定义**：设R是A上的关系，若**∀x,y∈A，若<x,y>∈R则<y,x>∈R**，则称R是对称的。

**反对称性定义**：设R是A上的关系，若**∀x,y∈A，若<x,y>∈R且<y,x>∈R则x=y**，则称R是反对称的。

**判定特征**：
- 对称：关系矩阵关于主对角线对称（m_ij=m_ji）；关系图中每条边都有反向边
- 反对称：关系矩阵中m_ij和m_ji不能同时为1（除非i=j）；关系图中任意两个不同顶点之间最多只有一条有向边
- **注意：存在既对称又反对称的关系**（如恒等关系、空关系）；也存在既不对称也不反对称的关系

**示例1**：R={<1,2>,<2,1>,<3,3>}，<1,2>与<2,1>成对出现，<3,3>自身对称，R是对称的。

**示例2**：R={<1,2>,<1,3>,<2,3>}，没有任何一对互为反向的不同元素有序对，R是反对称的。

**示例3**：R={<1,2>,<2,1>,<1,3>}，<1,2>与<2,1>成对（满足对称的部分），但<1,3>没有<3,1>（不满足对称），且<1,2>与<2,1>同时存在但1≠2（不满足反对称），故R既不对称也不反对称。

### 传递性〔CH4-04-03〕

**传递性定义**：设R是A上的关系，若**∀x,y,z∈A，若<x,y>∈R且<y,z>∈R则<x,z>∈R**，则称R是传递的。

**判定特征**：
- 关系矩阵：若m_ij=1且m_jk=1，则必须有m_ik=1
- 关系图：若存在x→y和y→z的边，则必须存在x→z的边
- 传递性是最容易出错的性质，必须检查所有长度为2的路径

**示例1**：R={<1,2>,<2,3>,<1,3>}，<1,2>→<2,3>需要<1,3>（存在），无其他可传递配对，R是传递的。

**示例2**：R={<1,2>,<2,3>}，<1,2>→<2,3>需要<1,3>但不存在，R不是传递的。

**示例3**：R={<1,1>,<1,2>,<2,1>,<2,2>}，检查：<1,2>→<2,1>需<1,1>（有），<2,1>→<1,2>需<2,2>（有），<1,1>→<1,2>需<1,2>（有），所有配对都满足，R是传递的。

### 关系性质的运算保持〔CH4-04-04〕

**核心结论**（运算后性质是否保持）：

| 运算 | 自反 | 反自反 | 对称 | 反对称 | 传递 |
|------|------|--------|------|--------|------|
| R∪S | 保持 | 保持 | 保持 | 不一定 | 不一定 |
| R∩S | 保持 | 保持 | 保持 | 保持 | 保持 |
| R-S | 不一定 | 保持 | 不一定 | 保持 | 不一定 |
| R^(-1) | 保持 | 保持 | 保持 | 保持 | 保持 |
| R∘S | 保持 | 不一定 | 不一定 | 不一定 | 不一定 |

**示例1**：两个自反关系的并仍是自反的：R和S都含所有<x,x>，R∪S也含所有<x,x>。

**示例2**：两个传递关系的并不一定传递：R={<1,2>}，S={<2,3>}都传递（空真），但R∪S={<1,2>,<2,3>}不传递（缺<1,3>）。

**示例3**：逆关系保持所有性质：R传递则R^(-1)也传递，因为<y,x>∈R^(-1)且<z,y>∈R^(-1)等价于<x,y>∈R且<y,z>∈R，由R传递得<x,z>∈R，即<z,x>∈R^(-1)。

## 五、关系的闭包〔CH4-05〕

### 自反闭包〔CH4-05-01〕

**定义**：设R是A上的关系，R的自反闭包r(R)是满足以下条件的最小关系：
1. r(R)是自反的
2. R⊆r(R)
3. 对任何自反关系R'，若R⊆R'则r(R)⊆R'

**计算公式**：**r(R) = R ∪ I_A**（R与恒等关系的并）

**关系矩阵**：M(r(R)) = M_R ∨ M(I_A)（对角线全部置1）

**示例1**：A={1,2,3}，R={<1,2>,<2,3>}，I_A={<1,1>,<2,2>,<3,3>}，r(R)={<1,2>,<2,3>,<1,1>,<2,2>,<3,3>}。

**示例2**：若R已经是自反的，则r(R)=R。如R={<1,1>,<2,2>,<1,2>}已自反，r(R)=R。

**示例3**：空关系∅的自反闭包r(∅)=∅∪I_A=I_A，即恒等关系。

### 对称闭包〔CH4-05-02〕

**定义**：设R是A上的关系，R的对称闭包s(R)是满足以下条件的最小关系：
1. s(R)是对称的
2. R⊆s(R)
3. 对任何对称关系R'，若R⊆R'则s(R)⊆R'

**计算公式**：**s(R) = R ∪ R^(-1)**（R与逆关系的并）

**关系矩阵**：M(s(R)) = M_R ∨ M_R^T（矩阵与其转置取或）

**示例1**：A={1,2,3}，R={<1,2>,<2,3>}，R^(-1)={<2,1>,<3,2>}，s(R)={<1,2>,<2,3>,<2,1>,<3,2>}。

**示例2**：若R已经是对称的，则s(R)=R。如R={<1,2>,<2,1>}已对称，s(R)=R。

**示例3**：R={<1,1>,<1,2>}，R^(-1)={<1,1>,<2,1>}，s(R)={<1,1>,<1,2>,<2,1>}，自环<1,1>在并中只出现一次。

### 传递闭包〔CH4-05-03〕

**定义**：设R是A上的关系，R的传递闭包t(R)是满足以下条件的最小关系：
1. t(R)是传递的
2. R⊆t(R)
3. 对任何传递关系R'，若R⊆R'则t(R)⊆R'

**计算公式**：
- **一般公式**：t(R) = R ∪ R^2 ∪ R^3 ∪ ...（所有正幂 R^i 的并，i=1,2,3,...）
- **有穷集公式**：若|A|=n，则 **t(R) = R ∪ R^2 ∪ ... ∪ R^n**（只需算到n次幂）

**关系矩阵**：M(t(R)) = M_R ∨ M_R^2 ∨ ... ∨ M_R^n（矩阵布尔乘后取或）

**Warshall算法**：高效计算传递闭包，逐步以每个顶点作为中间点更新可达矩阵。

**示例1**：A={1,2,3}，R={<1,2>,<2,3>}，R^2={<1,3>}，R^3=∅，t(R)=R∪R^2={<1,2>,<2,3>,<1,3>}。

**示例2**：A={1,2,3,4}，R={<1,2>,<2,3>,<3,4>}，R^2={<1,3>,<2,4>}，R^3={<1,4>}，R^4=∅，t(R)={<1,2>,<2,3>,<3,4>,<1,3>,<2,4>,<1,4>}，共6条边（完全链的所有可达边）。

**示例3**：若R已经是传递的，则t(R)=R。如R={<1,2>,<2,3>,<1,3>}已传递，t(R)=R。

### 闭包的性质〔CH4-05-04〕

**基本性质**：
- R自反 ⇔ r(R)=R；R对称 ⇔ s(R)=R；R传递 ⇔ t(R)=R
- **rs(R) = sr(R)**（先自反后对称 = 先对称后自反）
- **rt(R) = tr(R)**（先自反后传递 = 先传递后自反）
- **st(R) ⊆ ts(R)**（先对称后传递 包含于 先传递后对称，一般不等）
- 若R⊆S，则r(R)⊆r(S)，s(R)⊆s(S)，t(R)⊆t(S)（闭包的单调性）

**示例1**：验证rs(R)=sr(R)：rs(R)=s(R∪I_A)=(R∪I_A)∪(R∪I_A)^(-1)=R∪I_A∪R^(-1)∪I_A=R∪R^(-1)∪I_A；sr(R)=r(R∪R^(-1))=(R∪R^(-1))∪I_A，两者相等。

**示例2**：st(R)⊆ts(R)的理解：先传递再对称得到的关系更大，因为对称化可能引入新的非传递边，再传递闭包会补充更多边。

**示例3**：闭包单调性：R={<1,2>}⊆S={<1,2>,<2,3>}，t(R)={<1,2>}⊆t(S)={<1,2>,<2,3>,<1,3>}。

## 六、等价关系〔CH4-06〕

### 等价关系的定义〔CH4-06-01〕

**定义**：设R是A上的关系，若R同时满足**自反性、对称性、传递性**，则称R为A上的等价关系。

**核心要点**：三个性质缺一不可，必须逐一验证。

**示例1**：A={1,2,3}，R={<1,1>,<2,2>,<3,3>,<1,2>,<2,1>}。自反（对角线全）、对称（<1,2>与<2,1>成对）、传递（<1,2>→<2,1>需<1,1>有，<2,1>→<1,2>需<2,2>有），故R是等价关系。

**示例2**：整数集Z上的模n同余关系 ≡_n = {<x,y>|x,y∈Z且n整除(x-y)}是等价关系。自反（n|0）、对称（n|(x-y)则n|(y-x)）、传递（n|(x-y)且n|(y-z)则n|(x-z)）。

**示例3**：三角形的相似关系是等价关系（每个三角形与自身相似、相似对称、相似可传递）。

### 等价类与商集〔CH4-06-02〕

**等价类定义**：设R是A上的等价关系，∀x∈A，**[x]_R = { y | y∈A 且 <x,y>∈R }**，称为x关于R的等价类，简称x的等价类。x称为该等价类的代表元。

**商集定义**：A上关于R的所有等价类构成的集合称为A关于R的商集，记作 **A/R = { [x]_R | x∈A }**。

**等价类的性质**：
- ∀x∈A，[x]_R非空且x∈[x]_R（自反性保证）
- ∀x,y∈A，要么[x]_R=[y]_R，要么[x]_R∩[y]_R=∅
- **∪{ [x]_R | x∈A } = A**（所有等价类的并为全集）
- 同一等价类中的元素互相等价，不同等价类中的元素互不等价

**示例1**：A={1,2,3,4}，R={<1,1>,<2,2>,<3,3>,<4,4>,<1,2>,<2,1>,<3,4>,<4,3>}，[1]={1,2}=[2]，[3]={3,4}=[4]，A/R={{1,2},{3,4}}。

**示例2**：Z上模3同余关系，[0]={...,-6,-3,0,3,6,...}，[1]={...,-5,-2,1,4,7,...}，[2]={...,-4,-1,2,5,8,...}，Z/≡_3={[0],[1],[2]}，共3个等价类。

**示例3**：A={a,b,c}上的全域关系E_A，[a]=[b]=[c]={a,b,c}，A/E_A={{a,b,c}}，只有1个等价类。

### 集合的划分〔CH4-06-03〕

**定义**：设A是非空集合，π是A的子集族（π⊆P(A)），若π满足：
1. ∅∉π（每个分块非空）
2. ∀B,C∈π，若B≠C则B∩C=∅（分块之间不相交）
3. **∪π = A**（所有分块的并为A）

则称π为A的一个划分，π中的元素称为划分块。

**等价关系与划分的对应**：
- 每个等价关系R确定一个划分A/R（商集）
- 每个划分π确定一个等价关系R_π = ∪{ B×B | B∈π }（同一块内的元素互相等价）
- **等价关系与划分是一一对应的**

**示例1**：A={1,2,3,4}，π={{1,2},{3},{4}}是A的划分，有3个划分块。对应的等价关系R={<1,1>,<2,2>,<1,2>,<2,1>,<3,3>,<4,4>}。

**示例2**：A={1,2,3}的所有划分：{{1,2,3}}（1块）、{{1},{2,3}}、{{2},{1,3}}、{{3},{1,2}}（2块）、{{1},{2},{3}}（3块），共5种划分。

**示例3**：π={{1,2},{2,3}}不是划分，因为{1,2}∩{2,3}={2}≠∅，分块相交了。

## 七、偏序关系〔CH4-07〕

### 偏序关系的定义〔CH4-07-01〕

**定义**：设R是A上的关系，若R同时满足**自反性、反对称性、传递性**，则称R为A上的偏序关系（半序关系），记作 ≼。

**偏序集**：集合A与A上的偏序关系≼一起称为偏序集，记作 <A,≼>。

**可比与不可比**：设<A,≼>为偏序集，∀x,y∈A，若x≼y或y≼x，则称x与y可比；否则称x与y不可比。

**全序关系**：若偏序集中任意两个元素都可比，则称该偏序关系为全序关系（线序关系），对应的偏序集称为全序集。

**示例1**：实数集上的小于等于关系≤是偏序关系（自反、反对称、传递），且任意两个实数都可比，故≤是全序关系。

**示例2**：正整数集上的整除关系|是偏序关系（自反：a|a；反对称：a|b且b|a则a=b；传递：a|b且b|c则a|c），但2和3不可比（互不整除），故整除关系不是全序关系。

**示例3**：集合族上的包含关系⊆是偏序关系（自反、反对称、传递），但{1}和{2}不可比，故不是全序关系。

### 哈斯图〔CH4-07-02〕

**定义**：哈斯图是偏序关系的简化图形表示。设<A,≼>为偏序集：
- 小元素画在下方，大元素画在上方
- 省略自环（自反性默认）
- 省略传递产生的边（若x≼y且y≼z，则不画x到z的边，只画x→y和y→z）
- **只画"盖住"关系的边**：若x≺y（x≼y且x≠y）且不存在z使x≺z≺y，则称y盖住x，画x到y的边

**画法步骤**：
1. 确定每个元素的层级（极小元在最底层）
2. 若y盖住x，在x和y之间连线
3. 箭头方向默认从下到上，可省略箭头

**示例1**：A={1,2,3,6}，偏序为整除关系。哈斯图：1在最底层，2和3在第二层（都盖住1），6在第三层（盖住2和3）。连线：1-2，1-3，2-6，3-6。

**示例2**：A={2,3,6,12}，偏序为整除关系。2和3在底层（不可比），6盖住2和3在中层，12盖住6在顶层。注意2不直接连12（因为2≺6≺12，6是中间元素）。

**示例3**：P({1,2})={∅,{1},{2},{1,2}}，偏序为包含关系。∅在底层，{1}和{2}在第二层（都盖住∅），{1,2}在顶层（盖住{1}和{2}）。

### 偏序集中的特殊元素〔CH4-07-03〕

**定义**：设<A,≼>为偏序集，B⊆A：

- **最大元**：若∃b∈B，∀x∈B都有x≼b，则称b为B的最大元。（与所有元素可比且最大）
- **最小元**：若∃b∈B，∀x∈B都有b≼x，则称b为B的最小元。（与所有元素可比且最小）
- **极大元**：若∃b∈B，∀x∈B，若b≼x则x=b，则称b为B的极大元。（没有比它更大的元素）
- **极小元**：若∃b∈B，∀x∈B，若x≼b则x=b，则称b为B的极小元。（没有比它更小的元素）
- **上界**：若∃a∈A，∀x∈B都有x≼a，则称a为B的上界。
- **下界**：若∃a∈A，∀x∈B都有a≼x，则称a为B的下界。
- **最小上界（上确界）**：B的上界中的最小元，记作sup(B)或LUB(B)。
- **最大下界（下确界）**：B的下界中的最大元，记作inf(B)或GLB(B)。

**关键区别**：最大元必须与B中所有元素可比；极大元只要求没有更大的元素（不需要与所有元素可比）。最大元唯一（若存在），极大元可以有多个。

**示例1**：A={1,2,3,6}，整除偏序，B={2,3,6}。最大元=6（6与2,3都可比且最大）；最小元不存在（2和3不可比）；极大元=6；极小元=2,3。

**示例2**：A={1,2,3,6}，整除偏序，B={2,3}。上界=6（2|6且3|6）；下界=1（1|2且1|3）；上确界=6；下确界=1。

**示例3**：A={2,3,4,6,8,12}，整除偏序，B={4,6}。上界=12（4|12且6|12，8不是上界因为6不整除8）；下界=2（2|4且2|6，3不是下界因为3不整除4）；上确界=12；下确界=2。

### 全序与良序〔CH4-07-04〕

**全序（线序）**：偏序集中任意两个元素都可比，则该偏序为全序关系。全序集的哈斯图是一条链。

**良序**：设<A,≼>为全序集，若A的每个非空子集都有最小元，则称≼为良序关系，<A,≼>为良序集。

**基本性质**：
- 所有有限全序集都是良序集
- 自然数集<N,≤>是良序集（每个非空自然数子集都有最小元）
- 整数集<Z,≤>不是良序集（如负整数集没有最小元）
- 实数集<R,≤>不是良序集（如(0,1)没有最小元）

**示例1**：A={1,2,3,4}，≤关系是全序也是良序，哈斯图为1-2-3-4的一条链。

**示例2**：N上的≤是良序：任何非空自然数子集都有最小元素（最小自然数原理）。

**示例3**：Z上的≤不是良序：子集{...,-3,-2,-1}没有最小元，可以无限减小。

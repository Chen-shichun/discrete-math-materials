# 第2章 谓词逻辑

## 一、谓词逻辑的基本概念〔CH2-01〕

### 个体词与谓词〔CH2-01-01〕

**个体词**：研究对象中可以独立存在的具体或抽象的客体。表示具体或特定客体的个体词称为**个体常元**，用 a, b, c 表示；表示抽象或泛指的个体词称为**个体变元**，用 x, y, z 表示。个体变元的取值范围称为**个体域**（论域），最大的个体域由宇宙间一切事物组成，称为**全总个体域**。

**谓词**：刻画个体词性质及个体词之间相互关系的词。表示具体性质或关系的谓词称为**谓词常元**，表示抽象或泛指的谓词称为**谓词变元**，都用 F, G, H 等大写字母表示。

**n 元谓词**：含有 n（n≥1）个个体变元的谓词称为 n 元谓词，记作 P(x1, x2, ..., xn)。一元谓词刻画一个个体的性质，多元谓词刻画多个个体之间的关系。不带个体变元的谓词（n=0）称为**0元谓词**，0元谓词就是命题。

示例1：设 F(x) 表示"x 是偶数"，a 表示 4，则 F(a) 表示"4 是偶数"，是真命题。
示例2：设 L(x,y) 表示"x 大于 y"，则 L(5,3) 表示"5 大于 3"，是真命题；L(3,5) 是假命题。
示例3：设 G(x) 表示"x 是素数"，则 G(x) 本身不是命题（x 未指定），是一元谓词；当 x 取具体值后才成为命题。

### 量词〔CH2-01-02〕

**全称量词 ∀**：表示"所有的""一切""任意的""每一个"。∀x 表示对个体域中的所有个体 x。∀xF(x) 表示个体域中所有个体都有性质 F。

**存在量词 ∃**：表示"存在着""有一个""至少有一个"。∃x 表示个体域中存在至少一个个体 x。∃xF(x) 表示个体域中存在至少一个个体有性质 F。

**特性谓词**：当使用全总个体域时，需要用一个谓词来限定个体的范围，这个谓词称为特性谓词。全称量词中特性谓词作为蕴含式的前件加入；存在量词中特性谓词作为合取项加入。

示例1：设个体域为实数集，F(x) 表示"x 是有理数"，则 ∀xF(x) 表示"所有实数都是有理数"（假命题），∃xF(x) 表示"存在有理数"（真命题）。
示例2：设 M(x) 表示"x 是人"（特性谓词），F(x) 表示"x 会死"，则"所有人都会死"符号化为 ∀x(M(x)→F(x))。
示例3：设 M(x) 表示"x 是人"，G(x) 表示"x 会飞"，则"有人会飞"符号化为 ∃x(M(x)∧G(x))。

### 命题符号化（谓词逻辑）〔CH2-01-03〕

将自然语言命题翻译为谓词公式的步骤：
1. 确定个体域（默认使用全总个体域）。
2. 分析命题中涉及的个体性质和关系，定义谓词。
3. 根据"所有"用∀、"存在"用∃选择量词。
4. 全称量词后用蕴含式（特性谓词作前件），存在量词后用合取式（特性谓词作合取项）。

常见模式：
- "所有 S 都是 P"：∀x(S(x)→P(x))
- "所有 S 都不是 P"：∀x(S(x)→¬P(x))
- "有的 S 是 P"：∃x(S(x)∧P(x))
- "有的 S 不是 P"：∃x(S(x)∧¬P(x))

示例1："每个学生都要考试"符号化为 ∀x(S(x)→E(x))，其中 S(x)：x 是学生，E(x)：x 要考试。
示例2："有的整数是偶数"符号化为 ∃x(I(x)∧E(x))，其中 I(x)：x 是整数，E(x)：x 是偶数。
示例3："没有不犯错误的人"符号化为 ¬∃x(M(x)∧¬F(x))，其中 M(x)：x 是人，F(x)：x 犯错误。（等价于 ∀x(M(x)→F(x))）

## 二、谓词公式与解释〔CH2-02〕

### 谓词公式的定义〔CH2-02-01〕

**项**的递归定义：
1. 个体常元和个体变元是项。
2. 若 f 是 n 元函数，t1, ..., tn 是项，则 f(t1, ..., tn) 是项。
3. 有限次使用以上规则得到的才是项。

**原子公式**：若 P 是 n 元谓词，t1, ..., tn 是项，则 P(t1, ..., tn) 称为原子谓词公式。

**合式公式（谓词公式）**的递归定义：
1. 原子公式是合式公式。
2. 若 A 是合式公式，则 ¬A 是合式公式。
3. 若 A、B 是合式公式，则 (A∧B)、(A∨B)、(A→B)、(A↔B) 是合式公式。
4. 若 A 是合式公式，x 是个体变元，则 ∀xA 和 ∃xA 是合式公式。
5. 有限次使用以上规则得到的才是合式公式。

示例1：∀x(F(x)→G(x))、∃y(H(y)∧¬K(y)) 都是合式公式。
示例2：F(x)→∀x 不是合式公式（量词后缺少公式）。
示例3：∀x∃yL(x,y) 是合式公式，表示"对每个 x 都存在 y 使得 x 与 y 有关系 L"。

### 自由变元与约束变元〔CH2-02-02〕

**指导变元**：在量词 ∀x 或 ∃x 中的 x 称为指导变元（作用变元）。

**辖域（作用域）**：量词后面紧跟着的最短公式称为该量词的辖域。

**约束出现**：在量词辖域中，指导变元的所有出现称为约束出现，约束出现的变元称为**约束变元**。

**自由出现**：除约束出现以外的变元出现称为自由出现，自由出现的变元称为**自由变元**。

示例1：在 ∀x(F(x)→G(x,y)) 中，∀x 的辖域是 (F(x)→G(x,y))，x 是约束变元，y 是自由变元。
示例2：在 ∃xF(x)∧G(x) 中，∃x 的辖域是 F(x)，F(x) 中的 x 是约束变元，G(x) 中的 x 是自由变元（两者是不同的变元）。
示例3：在 ∀x(F(x)→∃yH(x,y)) 中，∀x 的辖域是整个公式，∃y 的辖域是 H(x,y)；x 和 y 都是约束变元。

### 换名规则与代替规则〔CH2-02-03〕

**换名规则**：将量词辖域中出现的某个约束变元及对应的指导变元，改成本辖域中未曾出现过的个体变元符号，公式其余部分不变。目的是避免一个变元既是约束出现又是自由出现，或在不同量词辖域中同名引起混淆。

**代替规则（自由变元代入）**：对某自由出现的个体变元，用与原公式中所有变元符号都不相同的符号去代替，且处处代替。

换名规则针对约束变元，代替规则针对自由变元，两者效果相同，使用其一即可。

示例1：对 ∃xF(x)∧G(x) 用换名规则，将约束变元 x 改为 y，得 ∃yF(y)∧G(x)，此时 x 仅为自由变元，消除了同名歧义。
示例2：对 ∀xF(x,y)∧∃xG(x) 用换名规则，将第二个量词的 x 改为 z，得 ∀xF(x,y)∧∃zG(z)。
示例3：对 ∀x(F(x)→G(x,y)) 用代替规则，将自由变元 y 代换为 z，得 ∀x(F(x)→G(x,z))。

### 解释与公式分类〔CH2-02-04〕

**解释 I** 由以下四部分组成：
1. 非空个体域 D。
2. D 中一部分特定元素（解释个体常元）。
3. D 上特定的函数（解释函数变元）。
4. D 上特定的谓词（解释谓词变元）。

一个公式在给定解释下，如果不含自由变元，则成为具有确定真值的命题；如果含自由变元，还需对自由变元赋值才能确定真值。

**公式分类**：
- **永真式（逻辑有效式）**：在任何解释下均为真的公式。
- **矛盾式（永假式）**：在任何解释下均为假的公式。
- **可满足式**：至少存在一个解释使其为真的公式。

**代换实例**：设 A0 是含命题变元 p1, ..., pn 的命题公式，A1, ..., An 是 n 个谓词公式，用 Ai 处处代换 pi 所得公式 A 称为 A0 的代换实例。命题逻辑中的重言式的代换实例都是谓词逻辑中的永真式，矛盾式的代换实例都是矛盾式。

示例1：∀xF(x)→∀xF(x) 是永真式（命题公式 p→p 的代换实例）。
示例2：∀xF(x)∧¬∀xF(x) 是矛盾式（p∧¬p 的代换实例）。
示例3：∀x∃yF(x,y) 是可满足式（取 F 为"小于"，个体域为整数集时为真）。

## 三、谓词逻辑等值演算〔CH2-03〕

### 等值的定义〔CH2-03-01〕

设 A、B 是两个谓词公式，若 A↔B 是永真式，则称 A 与 B 等值，记作 **A ⇔ B**。

命题逻辑中的 16 组基本等值式的代换实例都是谓词逻辑的等值式，例如：
- **双重否定律**：¬¬A ⇔ A
- **蕴含等值式**：A→B ⇔ ¬A∨B
- **德摩根律**：¬(A∧B) ⇔ ¬A∨¬B

示例1：∀xF(x)→∃xG(x) ⇔ ¬∀xF(x)∨∃xG(x)（蕴含等值式的代换实例）。
示例2：¬(∀xF(x)∧∃xG(x)) ⇔ ¬∀xF(x)∨¬∃xG(x)（德摩根律的代换实例）。
示例3：∀xF(x)∨∀xF(x) ⇔ ∀xF(x)（幂等律的代换实例）。

### 量词否定等值式〔CH2-03-02〕

**量词否定等值式**：
- **¬∀xA(x) ⇔ ∃x¬A(x)**
- **¬∃xA(x) ⇔ ∀x¬A(x)**

含义："不是所有 x 都有性质 A"等值于"存在 x 没有性质 A"；"不存在 x 有性质 A"等值于"所有 x 都没有性质 A"。

示例1：¬∀x(M(x)→F(x)) ⇔ ∃x¬(M(x)→F(x)) ⇔ ∃x(M(x)∧¬F(x))，即"不是所有人都犯错误"等值于"有人不犯错误"。
示例2：¬∃x(M(x)∧G(x)) ⇔ ∀x¬(M(x)∧G(x)) ⇔ ∀x(M(x)→¬G(x))，即"没有人会飞"等值于"所有人都不会飞"。
示例3：¬∀x∃yF(x,y) ⇔ ∃x¬∃yF(x,y) ⇔ ∃x∀y¬F(x,y)，逐层将否定内移。

### 量词辖域收缩与扩张等值式〔CH2-03-03〕

设 A(x) 是含 x 自由出现的公式，B 中不含 x 的自由出现，则：

**全称量词辖域收缩与扩张**：
- **∀x(A(x)∨B) ⇔ ∀xA(x)∨B**
- **∀x(A(x)∧B) ⇔ ∀xA(x)∧B**
- **∀x(A(x)→B) ⇔ ∃xA(x)→B**
- **∀x(B→A(x)) ⇔ B→∀xA(x)**

**存在量词辖域收缩与扩张**：
- **∃x(A(x)∨B) ⇔ ∃xA(x)∨B**
- **∃x(A(x)∧B) ⇔ ∃xA(x)∧B**
- **∃x(A(x)→B) ⇔ ∀xA(x)→B**
- **∃x(B→A(x)) ⇔ B→∃xA(x)**

注意：当 B 中不含 x 的自由出现时，量词可以越过 B 收缩或扩张。蕴含式方向变化时量词会发生∀与∃的互换。

示例1：∀x(F(x)∨G) ⇔ ∀xF(x)∨G（G 不含 x）。
示例2：∃x(F(x)∧G) ⇔ ∃xF(x)∧G。
示例3：∀x(F(x)→G) ⇔ ∃xF(x)→G（前件中量词扩张后变为存在量词）。

### 量词分配等值式〔CH2-03-04〕

**全称量词对合取的分配**：
- **∀x(A(x)∧B(x)) ⇔ ∀xA(x)∧∀xB(x)**

**存在量词对析取的分配**：
- **∃x(A(x)∨B(x)) ⇔ ∃xA(x)∨∃xB(x)**

注意：∀ 对 ∨ 不满足分配等值式，∃ 对 ∧ 不满足分配等值式，即：
- ∀x(A(x)∨B(x)) 与 ∀xA(x)∨∀xB(x) 不等值
- ∃x(A(x)∧B(x)) 与 ∃xA(x)∧∃xB(x) 不等值

但有以下蕴含关系：
- ∀xA(x)∨∀xB(x) ⇒ ∀x(A(x)∨B(x))
- ∃x(A(x)∧B(x)) ⇒ ∃xA(x)∧∃xB(x)

示例1：∀x(F(x)∧G(x)) ⇔ ∀xF(x)∧∀xG(x)，"所有 x 既是 F 又是 G"等值于"所有 x 是 F 且所有 x 是 G"。
示例2：∃x(F(x)∨G(x)) ⇔ ∃xF(x)∨∃xG(x)，"存在 x 是 F 或 G"等值于"存在 x 是 F 或存在 x 是 G"。
示例3：∀x(F(x)∨G(x)) 不等值于 ∀xF(x)∨∀xG(x)。反例：个体域为整数，F(x)：x 是偶数，G(x)：x 是奇数，左边为真（每个整数是偶或奇），右边为假（并非所有整数是偶数，也并非所有整数是奇数）。

### 多个量词的等值式〔CH2-03-05〕

多个量词同时出现时，**全称量词之间可以交换顺序，存在量词之间可以交换顺序**，但全称量词与存在量词之间一般不能随意交换顺序。

- **∀x∀yA(x,y) ⇔ ∀y∀xA(x,y)**
- **∃x∃yA(x,y) ⇔ ∃y∃xA(x,y)**

∀x∃yA(x,y) 与 ∃y∀xA(x,y) 不等值，但有蕴含关系：
- **∃y∀xA(x,y) ⇒ ∀x∃yA(x,y)**

示例1：∀x∀yL(x,y) ⇔ ∀y∀xL(x,y)，"所有 x 对所有 y 有关系 L"与"所有 y 对所有 x 有关系 L"等值。
示例2：∀x∃yL(x,y) 与 ∃y∀xL(x,y) 不等值。取个体域为整数，L(x,y)：x<y。左边"对每个整数 x 都存在更大的整数 y"为真；右边"存在一个整数 y 比所有整数 x 都大"为假。
示例3：∃x∃yF(x,y) ⇔ ∃y∃xF(x,y)，存在量词可交换。

## 四、前束范式〔CH2-04〕

### 前束范式的定义〔CH2-04-01〕

**前束范式**：设 A 是一个谓词公式，若 A 具有如下形式：
Q1x1Q2x2...QkxkB
其中 Qi（1≤i≤k）为 ∀ 或 ∃，B 为不含量词的谓词公式，则称 A 为前束范式。Q1x1...Qkxk 称为前束（首标），B 称为母式。

**前束范式存在定理**：任何谓词公式都存在与之等值的前束范式。

注意：一个公式的前束范式不唯一（等值的前束范式可以有不同形式）。

示例1：∀x∃y(F(x)→G(y)) 是前束范式，前束为 ∀x∃y，母式为 F(x)→G(y)。
示例2：∀xF(x)∧∃xG(x) 不是前束范式（量词未全部前置），其前束范式可为 ∀x∃y(F(x)∧G(y))。
示例3：¬∀x∃yF(x,y) 不是前束范式，需先将否定内移再前置量词。

### 前束范式的求法〔CH2-04-02〕

求前束范式的步骤：
1. 消去 → 和 ↔（用蕴含等值式和等价等值式）。
2. 将 ¬ 内移到谓词前（用量词否定等值式和德摩根律）。
3. 利用换名规则或代替规则，使所有约束变元互不相同，且约束变元与自由变元不重名。
4. 利用量词辖域收缩与扩张等值式，将所有量词逐步移到公式最前面。

示例1：求 ∀xF(x)→¬∃xG(x) 的前束范式。
步骤1：消去→，得 ¬∀xF(x)∨¬∃xG(x)。
步骤2：否定内移，得 ∃x¬F(x)∨∀x¬G(x)。
步骤3：换名，得 ∃x¬F(x)∨∀y¬G(y)。
步骤4：量词前置，得 ∃x∀y(¬F(x)∨¬G(y))。

示例2：求 ∀xF(x)∧∃xG(x) 的前束范式。
步骤1：换名，得 ∀xF(x)∧∃yG(y)。
步骤2：量词前置（∀对∧分配、∃对∧扩张），得 ∀x∃y(F(x)∧G(y))。

示例3：求 ¬(∀xF(x)→∃xG(x)) 的前束范式。
步骤1：消去→，得 ¬(¬∀xF(x)∨∃xG(x))。
步骤2：德摩根律，得 ∀xF(x)∧¬∃xG(x)。
步骤3：否定内移，得 ∀xF(x)∧∀x¬G(x)。
步骤4：换名并前置，得 ∀x∀y(F(x)∧¬G(y))。

## 五、谓词逻辑推理理论〔CH2-05〕

### 推理的形式结构〔CH2-05-01〕

设 A1, A2, ..., Ak, B 是谓词公式，若 (A1∧A2∧...∧Ak)→B 是永真式，则称从前提 A1, ..., Ak 推出结论 B 的推理正确，B 是有效结论，记作 **A1∧A2∧...∧Ak ⇒ B**。

命题逻辑中的推理定律（假言推理、拒取式、析取三段论、假言三段论等）的代换实例都是谓词逻辑的推理定律。

谓词逻辑中特有的推理定律：
- **∀xA(x)∨∀xB(x) ⇒ ∀x(A(x)∨B(x))**
- **∃x(A(x)∧B(x)) ⇒ ∃xA(x)∧∃xB(x)**
- **∀x(A(x)→B(x)) ⇒ ∀xA(x)→∀xB(x)**
- **∀x(A(x)→B(x)) ⇒ ∃xA(x)→∃xB(x)**
- **∃y∀xA(x,y) ⇒ ∀x∃yA(x,y)**

示例1：由 ∀x(F(x)→G(x)) 和 ∀xF(x) 推出 ∀xG(x)，这是假言推理在谓词逻辑中的应用。
示例2：∃x(F(x)∧G(x)) ⇒ ∃xF(x)∧∃xG(x)，存在量词对合取的蕴含关系。
示例3：由 ∀x(F(x)→G(x)) 和 ∃xF(x) 推出 ∃xG(x)，这是常用的"三段论"推理。

### 量词消去与引入规则〔CH2-05-02〕

在自然推理系统中，有四条关于量词的推理规则：

**全称量词消去规则（UI规则/US规则）**：
从 ∀xA(x) 可推出 A(y) 或 A(c)，其中 y 是任意不在 A(x) 中约束出现的个体变元，c 是任意个体常元。
形式：∀xA(x) ⇒ A(y) 或 ∀xA(x) ⇒ A(c)。

**全称量词引入规则（UG规则/UG规则）**：
从 A(y) 可推出 ∀xA(x)，其中 y 取个体域中任何值时 A(y) 均为真，且 y 不在任何前提中自由出现，x 不在 A(y) 中约束出现。
形式：A(y) ⇒ ∀xA(x)。

**存在量词消去规则（EI规则/ES规则）**：
从 ∃xA(x) 可推出 A(c)，其中 c 是使 A 为真的特定个体常元，且 c 不在此前的推导中出现过，也不在 A(x) 中出现。
形式：∃xA(x) ⇒ A(c)。

**存在量词引入规则（EG规则/EG规则）**：
从 A(c) 可推出 ∃xA(x)，其中 c 是个体常元，x 不在 A(c) 中出现。
形式：A(c) ⇒ ∃xA(x)。

使用注意：
- EI 规则引入的特定常元 c 不能在之前的推导中出现过。
- 若同时使用 UI 和 EI，应先使用 EI 再使用 UI，避免常元冲突。
- UG 规则要求 y 在前提中不自由出现，且 A(y) 对 y 的任意取值都成立。

示例1：由 ∀x(F(x)→G(x))，用 UI 规则得 F(c)→G(c)（c 为任意个体常元）。
示例2：由 ∃xF(x)，用 EI 规则得 F(c)（c 是使 F 为真的特定常元，此前未出现过）。
示例3：由 F(c)，用 EG 规则得 ∃xF(x)。

### 自然推理系统证明〔CH2-05-03〕

谓词逻辑自然推理系统在命题逻辑自然推理系统 P 的基础上，增加了 UI、UG、EI、EG 四条量词规则。证明格式与命题逻辑相同：每行写公式，注明前提或推理规则。

典型证明模式（三段论）：
前提：∀x(F(x)→G(x))，∃xF(x)
结论：∃xG(x)
证明：
(1) ∃xF(x)        前提引入
(2) F(c)           (1)EI规则
(3) ∀x(F(x)→G(x))  前提引入
(4) F(c)→G(c)      (3)UI规则
(5) G(c)           (2)(4)假言推理
(6) ∃xG(x)         (5)EG规则

注意：先 EI 后 UI，使 UI 中使用的常元与 EI 引入的一致。

示例1：证明：前提 ∀x(F(x)→G(x))，∀xF(x)，结论 ∀xG(x)。
(1) ∀xF(x)         前提引入
(2) F(y)           (1)UI规则（y为任意变元）
(3) ∀x(F(x)→G(x))  前提引入
(4) F(y)→G(y)      (3)UI规则
(5) G(y)           (2)(4)假言推理
(6) ∀xG(x)         (5)UG规则

示例2：证明：前提 ∀x(F(x)→¬G(x))，∃xH(x)∧G(x)，结论 ∃x(H(x)∧¬F(x))。
(1) ∃x(H(x)∧G(x))    前提引入
(2) H(c)∧G(c)         (1)EI规则
(3) H(c)              (2)化简
(4) G(c)              (2)化简
(5) ∀x(F(x)→¬G(x))    前提引入
(6) F(c)→¬G(c)        (5)UI规则
(7) ¬¬G(c)            (4)双重否定
(8) ¬F(c)             (6)(7)拒取式
(9) H(c)∧¬F(c)        (3)(8)合取引入
(10) ∃x(H(x)∧¬F(x))   (9)EG规则

示例3：证明"苏格拉底三段论"：所有人都会死，苏格拉底是人，所以苏格拉底会死。
设 M(x)：x 是人，D(x)：x 会死，s：苏格拉底。
前提：∀x(M(x)→D(x))，M(s)
结论：D(s)
(1) ∀x(M(x)→D(x))  前提引入
(2) M(s)→D(s)       (1)UI规则
(3) M(s)            前提引入
(4) D(s)             (2)(3)假言推理

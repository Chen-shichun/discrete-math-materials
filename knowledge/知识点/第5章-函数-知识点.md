# 第5章 函数

## 一、函数的基本概念〔CH5-01〕

### 函数的定义〔CH5-01-01〕

**定义**：设A、B为集合，若f是从A到B的关系（f⊆A×B），且对每个x∈A，都存在唯一的y∈B使得<x,y>∈f，则称f为从A到B的函数（映射），记作 f: A→B。

**核心要素**：
- 定义域 dom(f) = A（每个A中元素都必须有像）
- 值域 ran(f) ⊆ B（像的集合，不一定等于B）
- **唯一性**：每个x∈A只能对应一个y∈B（一对多不是函数）

**函数与关系的区别**：函数是特殊的二元关系，要求A中每个元素都出现在第一位置且只出现一次。关系不要求每个元素都有像，也不要求像唯一。

**示例1**：A={1,2,3}，B={a,b}，f={<1,a>,<2,b>,<3,a>}是函数，因为每个A中元素都有唯一的像。

**示例2**：R={<1,a>,<1,b>,<2,a>}不是函数，因为1对应了a和b两个像（不唯一）。

**示例3**：g={<1,a>,<2,b>}不是从A={1,2,3}到B的函数，因为3没有像（dom(g)={1,2}≠A）。

### 函数的表示方法〔CH5-01-02〕

**三种常用表示法**：

1. **集合表示法**：列出所有有序对，如f={<1,a>,<2,b>,<3,a>}。

2. **解析式表示法**：用公式表达对应规则，如f(x)=x^2+1，f: R→R。

3. **图示表示法**：用箭头图表示，左边定义域元素、右边陪域元素，箭头表示对应关系。

**函数相等**：两个函数f和g相等，当且仅当它们的定义域相同、陪域相同，且对定义域中每个元素x都有f(x)=g(x)。记作f=g。

**示例1**：f(x)=x^2，g(x)=x^2，f,g: R→R，则f=g（定义域、陪域、对应规则都相同）。

**示例2**：f(x)=x^2（f: R→R）与g(x)=x^2（g: R→[0,+∞)）不相等，因为陪域不同。

**示例3**：f(x)=|x|与g(x)=√(x^2)在R上相等，因为对每个实数x都有|x|=√(x^2)。

### 函数的定义域与值域〔CH5-01-03〕

**定义域**：dom(f) = { x | x∈A } = A（函数的定义域就是A本身）。

**值域（像集）**：ran(f) = f(A) = { f(x) | x∈A }，即所有像的集合。注意ran(f)⊆B，不一定等于B。

**像与原像**：
- 元素x的像：f(x)∈B
- 集合S⊆A的像：f(S) = { f(x) | x∈S }
- 集合T⊆B的原像：f^(-1)(T) = { x∈A | f(x)∈T }

**示例1**：f: {1,2,3}→{a,b,c}，f(1)=a, f(2)=a, f(3)=b，则ran(f)={a,b}，f({1,3})={a,b}。

**示例2**：f: R→R, f(x)=x^2，则ran(f)=[0,+∞)（非负实数），不是整个R。

**示例3**：f: R→R, f(x)=x^2，原像f^(-1)({4})={-2,2}（因为(-2)^2=4且2^2=4）。

### 特殊函数〔CH5-01-04〕

**常值函数**：f(x)=c（c为常数），对所有x∈A，f(x)都等于同一个值c。ran(f)={c}。

**恒等函数**：**I_A: A→A，I_A(x)=x**，每个元素映射到自身。恒等函数是双射。

**特征函数**：设A为全集，B⊆A，B的特征函数χ_B: A→{0,1}，χ_B(x)=1若x∈B，χ_B(x)=0若x∉B。

**投影函数**：从笛卡尔积到某一分量的函数，如π_1: A×B→A，π_1(<x,y>)=x。

**示例1**：f: R→R, f(x)=5是常值函数，ran(f)={5}，既不是单射也不是满射。

**示例2**：I_R: R→R, I_R(x)=x是恒等函数，既是单射又是满射（双射）。

**示例3**：设A={1,2,3,4}，B={2,4}，则χ_B(1)=0, χ_B(2)=1, χ_B(3)=0, χ_B(4)=1。

## 二、函数的性质〔CH5-02〕

### 单射（入射）〔CH5-02-01〕

**定义**：设f: A→B，若对任意x1,x2∈A，**x1≠x2 ⇒ f(x1)≠f(x2)**（等价于f(x1)=f(x2)⇒x1=x2），则称f为单射（入射、一对一函数）。

**判定方法**：
- 定义法：假设f(x1)=f(x2)，推导x1=x2
- 图像法：水平直线与图像最多一个交点
- 有限集：|A|≤|B|是单射的必要条件（不是充分条件）

**示例1**：f: R→R, f(x)=2x+1是单射。若2x1+1=2x2+1，则x1=x2。

**示例2**：f: R→R, f(x)=x^2不是单射。f(1)=f(-1)=1，但1≠-1。

**示例3**：f: {1,2,3}→{a,b,c,d}, f(1)=a, f(2)=c, f(3)=b是单射，三个像互不相同。

### 满射〔CH5-02-02〕

**定义**：设f: A→B，若**ran(f)=B**（即对每个y∈B，都存在x∈A使得f(x)=y），则称f为满射（到上函数、映上函数）。

**判定方法**：
- 定义法：对任意y∈B，解方程f(x)=y，证明存在x∈A
- 陪域中每个元素都有原像
- 有限集：|A|≥|B|是满射的必要条件（不是充分条件）

**示例1**：f: R→R, f(x)=x^3是满射。对任意y∈R，x=∛y∈R且f(x)=y。

**示例2**：f: R→R, f(x)=x^2不是满射。y=-1∈R，但x^2=-1无实数解。

**示例3**：f: {1,2,3}→{a,b}, f(1)=a, f(2)=b, f(3)=a是满射，a和b都有原像。

### 双射〔CH5-02-03〕

**定义**：设f: A→B，若f**既是单射又是满射**，则称f为双射（一一对应、一一到上函数）。

**核心性质**：
- 双射函数存在唯一的逆函数f^(-1)
- **f: A→B是双射 ⇔ 存在g: B→A使得g∘f=I_A且f∘g=I_B**
- 有限集：f: A→B是双射 ⇒ |A|=|B|
- 有限集：若|A|=|B|，则f是单射 ⇔ f是满射 ⇔ f是双射

**示例1**：f: R→R, f(x)=2x+1是双射。单射（已证）且满射（对任意y，x=(y-1)/2∈R）。

**示例2**：f: {1,2,3}→{a,b,c}, f(1)=b, f(2)=a, f(3)=c是双射，三个像互不相同且覆盖全部陪域。

**示例3**：f: N→N, f(n)=n+1不是双射。它是单射但不是满射（0没有原像）。

### 函数性质的判定方法〔CH5-02-04〕

**综合判定策略**：

| 性质 | 判定关键 | 反例构造 |
|------|----------|----------|
| 单射 | 不同输入→不同输出 | 找x1≠x2使f(x1)=f(x2) |
| 满射 | 陪域中每个元素都有原像 | 找y∈B使f(x)=y无解 |
| 双射 | 同时满足单射和满射 | 分别验证两条 |

**有限集上的特殊结论**：
- 若|A|>|B|，则f不可能是单射（鸽巢原理）
- 若|A|<|B|，则f不可能是满射
- 若|A|=|B|，单射、满射、双射三者等价

**示例1**：f: {1,2,3}→{a,b}不可能是单射（3>2，由鸽巢原理至少两个元素像相同）。

**示例2**：f: {1,2}→{a,b,c}不可能是满射（2<3，最多覆盖2个陪域元素）。

**示例3**：f: {1,2,3}→{a,b,c}，若f是单射则3个像互不相同，必然覆盖全部3个陪域元素，故也是满射，即双射。

## 三、函数的运算〔CH5-03〕

### 复合函数〔CH5-03-01〕

**定义**：设f: A→B，g: B→C，f与g的复合函数**g∘f: A→C**定义为 (g∘f)(x) = g(f(x))，对所有x∈A。

**注意方向**：g∘f表示先作用f，再作用g（f在右边先执行）。复合函数的定义域是A，陪域是C。

**复合的条件**：ran(f)⊆dom(g)，即f的值域必须包含在g的定义域中。

**基本性质**：
- **结合律**：(h∘g)∘f = h∘(g∘f)（当复合有意义时）
- **一般不满足交换律**：g∘f ≠ f∘g（即使都有意义）
- **与恒等函数的复合**：f∘I_A = f，I_B∘f = f
- **单射复合**：f和g都是单射 ⇒ g∘f是单射
- **满射复合**：f和g都是满射 ⇒ g∘f是满射
- **双射复合**：f和g都是双射 ⇒ g∘f是双射

**示例1**：f: R→R, f(x)=x^2；g: R→R, g(x)=x+1。则(g∘f)(x)=g(f(x))=g(x^2)=x^2+1；(f∘g)(x)=f(g(x))=f(x+1)=(x+1)^2。两者不相等，验证交换律不成立。

**示例2**：f: {1,2}→{a,b}, f(1)=a, f(2)=b；g: {a,b}→{x,y}, g(a)=x, g(b)=y。则(g∘f)(1)=g(a)=x，(g∘f)(2)=g(b)=y，g∘f: {1,2}→{x,y}。

**示例3**：验证结合律：f(x)=x+1, g(x)=2x, h(x)=x^2。((h∘g)∘f)(x)=(h∘g)(x+1)=h(g(x+1))=h(2x+2)=(2x+2)^2；(h∘(g∘f))(x)=h((g∘f)(x))=h(g(f(x)))=h(g(x+1))=h(2x+2)=(2x+2)^2，两者相等。

### 逆函数〔CH5-03-02〕

**定义**：设f: A→B是双射，则存在唯一的函数f^(-1): B→A，满足**f^(-1)(y)=x当且仅当f(x)=y**，称f^(-1)为f的逆函数（反函数）。

**存在条件**：**f是双射 ⇔ f存在逆函数**。非双射函数没有逆函数（其逆关系不是函数）。

**基本性质**：
- **(f^(-1))^(-1) = f**（逆函数的逆是原函数）
- **f^(-1)∘f = I_A**（先f后逆，回到原值）
- **f∘f^(-1) = I_B**（先逆后f，回到原值）
- **(g∘f)^(-1) = f^(-1)∘g^(-1)**（复合的逆等于逆的反序复合）
- 双射函数的逆函数也是双射

**求逆函数的方法**：
1. 验证f是双射（单射+满射）
2. 解方程y=f(x)，用y表示x，得到x=f^(-1)(y)
3. 交换x和y的记号，得到y=f^(-1)(x)

**示例1**：f: R→R, f(x)=2x+1是双射。由y=2x+1解得x=(y-1)/2，故f^(-1)(x)=(x-1)/2。验证：f^(-1)(f(x))=f^(-1)(2x+1)=(2x+1-1)/2=x。

**示例2**：f: R→R, f(x)=x^2没有逆函数，因为不是单射（f(1)=f(-1)=1），其逆关系一对多。

**示例3**：f: {1,2,3}→{a,b,c}, f(1)=b, f(2)=a, f(3)=c是双射。逆函数f^(-1): {a,b,c}→{1,2,3}, f^(-1)(a)=2, f^(-1)(b)=1, f^(-1)(c)=3。

### 函数的限制与延拓〔CH5-03-03〕

**函数的限制**：设f: A→B，C⊆A，f在C上的限制记作f|_C: C→B，定义为f|_C(x)=f(x)对所有x∈C。即缩小定义域。

**函数的延拓**：设f: C→B，g: A→B，其中C⊆A。若g|_C=f（即g在C上与f一致），则称g是f的延拓（扩张）。即扩大定义域。

**核心关系**：限制是缩小定义域，延拓是扩大定义域，两者互为逆操作。f|_C是唯一的，但f的延拓可以有多个。

**示例1**：f: R→R, f(x)=x^2，f在[0,+∞)上的限制f|_[0,+∞): [0,+∞)→R, f(x)=x^2。这个限制是单射（虽然原函数不是）。

**示例2**：f: {1,2}→{a,b}, f(1)=a, f(2)=b。g: {1,2,3}→{a,b}, g(1)=a, g(2)=b, g(3)=a是f的一个延拓（g在{1,2}上与f一致）。

**示例3**：f: N→N, f(n)=n是恒等函数。g: Z→Z, g(x)=x是f的延拓（N⊆Z，g在N上与f一致）。

## 四、集合的基数〔CH5-04〕

### 有限集与无限集〔CH5-04-01〕

**有限集**：若集合A与{1,2,...,n}（n为某个自然数）等势，则称A为有限集，其基数|A|=n。空集的基数为0。

**无限集**：不是有限集的集合称为无限集。

**等势（ equipotent ）**：若存在双射f: A→B，则称A与B等势（基数相同），记作A≈B或|A|=|B|。

**核心思想**：两个集合等势当且仅当它们的元素可以一一对应。有限集等势等价于元素个数相同；无限集的等势需要通过构造双射来判断。

**示例1**：A={a,b,c}，B={1,2,3}，存在双射f(a)=1, f(b)=2, f(c)=3，故A≈B，|A|=|B|=3。

**示例2**：N（自然数集）是无限集，因为不存在n使得N与{1,...,n}等势（N中元素比任何有限集都多）。

**示例3**：空集∅是有限集，|∅|=0。{∅}是有限集，|{∅}|=1。

### 可数集与不可数集〔CH5-04-02〕

**可数集（可列集）**：若集合A与自然数集N等势（存在双射f: N→A），则称A为可数无限集，简称可数集。有限集和可数无限集统称为至多可数集。

**可数集的性质**：
- 可数集的任何子集是至多可数集
- 可数个可数集的并是可数集
- **可数集的笛卡尔积是可数集**（N×N≈N）
- 整数集Z是可数集
- 有理数集Q是可数集

**不可数集**：不是至多可数集的无限集称为不可数集。

**实数集不可数**：**实数集R是不可数集**（康托尔对角线法证明）。区间(0,1)也是不可数集，且与R等势。

**连续统**：实数集R的基数称为连续统，记作c（或ℵ1在连续统假设下）。

**示例1**：N={0,1,2,3,...}是可数集，恒等函数I_N: N→N是双射。

**示例2**：Z={...,-2,-1,0,1,2,...}是可数集。双射f: N→Z可构造为：f(0)=0, f(1)=1, f(2)=-1, f(3)=2, f(4)=-2,...即偶数n→n/2，奇数n→-(n+1)/2。

**示例3**：(0,1)是不可数集。假设可数，将所有数排成十进制小数列表，对角线法构造新数b=0.b1b2b3...，其中bi≠第i个数的第i位，则b不在列表中，矛盾。

### 基数的比较〔CH5-04-03〕

**定义**：设A、B为集合，若存在单射f: A→B，则称A的基数不超过B的基数，记作|A|≤|B|。

**若|A|≤|B|且|B|≤|A|，则|A|=|B|**（康托尔-伯恩斯坦定理）。

**若|A|≤|B|且|A|≠|B|，则|A|<|B|。

**康托尔-伯恩斯坦定理**：若存在单射f: A→B和单射g: B→A，则存在双射h: A→B，即A≈B。这是证明两个集合等势的重要工具，不需要直接构造双射。

**基数的层级**：
- 有限集基数：0, 1, 2, 3, ...
- 可数无限集基数：ℵ0（阿列夫零）
- 连续统基数：c = 2^ℵ0
- **ℵ0 < c**（可数集基数小于连续统）

**示例1**：|N|=ℵ0，|Z|=ℵ0，|Q|=ℵ0，这些集合都是可数的，基数相同。

**示例2**：|R|=c，|(0,1)|=c，|[0,1]|=c，这些集合与实数集等势。

**示例3**：用康托尔-伯恩斯坦定理证明(0,1)≈[0,1]：单射f:(0,1)→[0,1], f(x)=x；单射g:[0,1]→(0,1), g(x)=x/4+1/4（映射到(1/4,3/4)⊂(0,1)）。两个方向都有单射，故等势。

### 康托尔定理〔CH5-04-04〕

**定理**：**对任何集合A，|A| < |P(A)|**（集合A的幂集的基数严格大于A的基数）。

**证明思路**：
1. 存在单射f: A→P(A)，f(x)={x}，故|A|≤|P(A)|。
2. 假设存在双射g: A→P(A)，构造集合B={x∈A | x∉g(x)}。
3. B∈P(A)，故存在b∈A使g(b)=B。
4. 问b∈B吗？若b∈B则b∉g(b)=B，矛盾；若b∉B则b∈g(b)=B，矛盾。
5. 故不存在双射，|A|≠|P(A)|，结合|A|≤|P(A)|得|A|<|P(A)|。

**推论**：不存在最大的基数。对任何基数，都有更大的基数（取幂集即可）。

**示例1**：A={1,2}，|A|=2，P(A)={∅,{1},{2},{1,2}}，|P(A)|=4=2^2，2<4。

**示例2**：|N|=ℵ0，|P(N)|=2^ℵ0=c，ℵ0<c。P(N)与实数集等势。

**示例3**：|P(R)|=2^c > c=|R|，幂集的幂集更大，以此类推，基数没有上限。

## 五、鸽巢原理与置换〔CH5-05〕

### 鸽巢原理〔CH5-05-01〕

**简单形式**：若把n+1个物品放入n个盒子，则至少有一个盒子中放有至少2个物品。

**一般形式**：若把m个物品放入n个盒子，则至少有一个盒子中放有至少 **⌈m/n⌉** 个物品（⌈⌉表示向上取整）。

**集合论表述**：设A、B为有限集，|A|>|B|，则对任何函数f: A→B，存在a1≠a2∈A使得f(a1)=f(a2)（即f不可能是单射）。

**加强形式**：若把q1+q2+...+qn-n+1个物品放入n个盒子，则至少存在某个i，第i个盒子中至少有qi个物品。

**应用步骤**：
1. 确定「物品」和「盒子」分别是什么
2. 计算物品数和盒子数
3. 应用鸽巢原理得出结论

**示例1**：13个人中至少有2个人在同一个月出生。物品=13人，盒子=12个月，13>12，由简单鸽巢原理。

**示例2**：从1到10中任取6个数，至少有两个数之和为11。构造5个盒子：{1,10},{2,9},{3,8},{4,7},{5,6}，取6个数放入5个盒子，至少一个盒子取了2个数，其和为11。

**示例3**：30个学生，至少有⌈30/12⌉=3个学生在同一个月出生。由一般形式，m=30, n=12, ⌈30/12⌉=⌈2.5⌉=3。

### 置换〔CH5-05-02〕

**定义**：有限集A上的双射f: A→A称为A上的一个置换。若|A|=n，则称f为n元置换。

**n元置换的个数**：**n元集合上共有n!个不同的置换**。

**置换的表示**：
1. **两行表示法**：f = ( 1 2 ... n ; f(1) f(2) ... f(n) )，第一行是定义域元素，第二行是对应像。
2. **轮换表示法**：将置换分解为不相交轮换的乘积。

**特殊置换**：
- 恒等置换：每个元素映射到自身，记作I或(1)(2)...(n)
- 对换：只交换两个元素，其余不动，记作(ab)
- 轮换(a1 a2 ... ak)：a1→a2→...→ak→a1

**置换的复合**：两个置换的复合仍是置换。置换复合一般不满足交换律。

**示例1**：A={1,2,3}，置换f: f(1)=2, f(2)=3, f(3)=1。两行表示为(1 2 3; 2 3 1)，轮换表示为(1 2 3)。这是一个3轮换。

**示例2**：3元集合上共有3!=6个置换：恒等(1)(2)(3)、(1 2)、(1 3)、(2 3)、(1 2 3)、(1 3 2)。

**示例3**：对换(1 2)表示1→2, 2→1, 3→3。复合(1 2)∘(1 2 3)：先(1 2 3)再(1 2)，1→2→1, 2→3→3, 3→1→2，结果为(2 3)。

### 递归函数〔CH5-05-03〕

**定义**：若函数的定义中引用了函数自身，则称为递归函数。递归定义必须包含：
1. **基础情形（基准情形）**：某些输入直接给出函数值
2. **递归步骤**：其他输入的函数值通过较小输入的函数值来定义

**数学归纳法与递归**：递归函数的正确性通常通过数学归纳法证明。

**常见递归函数**：
- 阶乘：0!=1，n!=n×(n-1)!（n≥1）
- 斐波那契数列：F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)（n≥2）
- 幂运算：a^0=1, a^n=a×a^(n-1)（n≥1）

**递归的要求**：递归步骤必须使问题规模严格减小，最终到达基础情形，否则会无限递归。

**示例1**：阶乘函数：5!=5×4!=5×4×3!=5×4×3×2!=5×4×3×2×1!=5×4×3×2×1×0!=120×1=120。

**示例2**：斐波那契数列：F(0)=0, F(1)=1, F(2)=F(1)+F(0)=1, F(3)=F(2)+F(1)=2, F(4)=F(3)+F(2)=3, F(5)=5。

**示例3**：幂函数递归：2^4=2×2^3=2×2×2^2=2×2×2×2^1=2×2×2×2×2^0=16×1=16。
